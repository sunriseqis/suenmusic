# SuenMusic 文档

单仓后，**记忆文件、开发文档、计划文档统一放这里**，不再散落在各子目录。

## 目录约定

```
docs/
├── memory/       长期记忆（跨会话有效的事实与口径）
│   ├── MEMORY.md          索引，一行一条指向具体文件
│   └── YYYY-MM-DD.md      某一天的排查/开发流水
├── dev/          开发文档（架构、环境搭建、构建与发布流程）
└── plan/         计划文档（尚未落地的方案、待验证的假设）
```

## 为什么集中在这里

原先拆成 `suenmusic-server/docs/` 与 `suenmusic-mobile/docs/` 两份，
同一个问题（比如「ArkTS 本地能不能编译」）在两边都可能有记录且容易互相矛盾。
合并后 `docs/memory/MEMORY.md` 是**唯一**的记忆索引。

## 目标模型档案

- [选歌系统目标模型](选歌系统目标模型.md) —— 选歌系统从建库到消费的**目标形态档案**，长期资产不随迭代废弃；验收以本文件为准，未来优化在此续写。

## 迁入与归档状态

单仓工程整合已于 2026-10-19 全面完成：

- 服务端源码：统一合并入 `server/`，生产依赖与数据库迁移均自持；
- Web 端：统一收敛在 `web/`，由服务端统一伺服；
- 移动端与原生套件：`ios/`、`android/`、`hw/` 与 `fn/`（飞牛原生套件）均已迁入主仓并对齐单一真相源架构；
- 外部旧仓 `suenmusic-server` 与 `suenmusic-mobile` 已对齐最新并设为只读。
