# 2026-10-27 iOS CI 编译与 Xcode 15 兼容性修复

## 背景与问题

在触发 GitHub Actions iOS 构建（`build-ios.yml`，运行在 `macos-14` 环境）时，构建任务在 `node scripts/build-ios.mjs --unsigned` 步骤中因 `xcodebuild` 失败，报告多项编译错误：

1. **AudioEngine.swift 缺少 Network 框架**：
   - `cannot find 'NWPathMonitor' in scope`
   - `cannot find type 'NWInterface' in scope`
2. **Swift 5.10 严格并发闭包捕获错误**：
   - `LiveActivityController.swift:102`: `reference to captured var 'self' in concurrently-executing code`
   - `AnchorSheet.swift:90, 96`: `reference to captured var 'self' in concurrently-executing code`
   原因：在 `addObserver` 闭包中使用 `[weak self]` 时，`self` 是弱引用可变变量（var）。嵌套在 `Task { @MainActor in self?.xxx() }` 中跨越并发隔离域时，Swift 5.10 判定为捕获可变变量并发执行。
3. **iOS 18 独占 API 未向下兼容**：
   - `TabBar.swift:43`: `value of type 'some View' has no member 'onGeometryChange'`
   原因：`.onGeometryChange` 为 iOS 18 / Xcode 16 新增 API，在 Xcode 15.4（iOS 17.5 SDK）中不存在。
4. **Target 部署目标版本异常**：
   - `The iOS deployment target 'IPHONEOS_DEPLOYMENT_TARGET' is set to 26.0, but the range of supported deployment target versions is 12.0 to 17.5.99`
5. **CI Xcode 版本选择脚本过于严格**：
   - `/Applications/Xcode_16.app` 不存在时回退到了系统默认的 `/Applications/Xcode.app`（即 Xcode 15.4）。

## 修复措施

1. **`ios/SuenMusic/Player/AudioEngine.swift`**：
   - 补充 `import Network`。
   - 优化 `diagTick` 中 `reason` 变量日志输出，避免无引用告警。
2. **`ios/SuenMusic/Player/LiveActivityController.swift` & `ios/SuenMusic/UI/AnchorSheet.swift`**：
   - 在 `addObserver` 闭包内加入 `guard let self else { return }` 进行不可变 `let` 常量强绑定后再进入 `Task { @MainActor in ... }`，彻底解决 Swift 5.10 的并发捕获报错。
3. **`ios/SuenMusic/UI/TabBar.swift`**：
   - 将 iOS 18 专有 `.onGeometryChange` 替换为向下兼容 iOS 16/17 的标准 SwiftUI 实现：
     ```swift
     .background(
         GeometryReader { geo in
             Color.clear
                 .onAppear { barW = geo.size.width }
                 .onChange(of: geo.size.width) { _, newW in barW = newW }
         }
     )
     ```
4. **`ios/App/App.xcodeproj/project.pbxproj`**：
   - 将 6 处 `IPHONEOS_DEPLOYMENT_TARGET = 26.0;` 全部调整为标准的 `IPHONEOS_DEPLOYMENT_TARGET = 17.0;`。
5. **`.github/workflows/build-ios.yml`**：
   - 改进 Xcode 版本查找与选择循环：优先匹配 `/Applications/Xcode_16*.app`，其次回退至 `/Applications/Xcode_15*.app`，并打印 `xcodebuild -version`。

## 验证结论

- 在 Mac 编译宿主机（Xcode 26.5 / iOS SDK）通过 `scripts/build-ios.mjs --unsigned` 进行完整编译验证：
  - `** BUILD SUCCEEDED **`
  - 成功打包出无签名 IPA：`app/unsigned/suenmusic-2.0.0.ipa`（1.8 MB）。
- 代码语法及 API 均已严格兼容 Xcode 15.4（iOS 17.5 SDK）及更高版本。
