## T9 卡片收口（2 项）

1. **设置页「卡片」区**（高级 tab，设备之后）：行「桌面卡片 / 已添加 N 张（或 未添加 / 查看）」——
   张数用 `formProvider.getPublishedRunningFormInfos()` 查（进页面查一次、点行再查一次）；
   点击弹单按钮说明：长按桌面 → 服务卡片 → 选 2×2 / 2×4；尺寸差异；按钮能做什么；**主题跟随设置里的主题**（跟随系统时按系统）。
2. **快照推送节流核对**（T9 §1.1-2「进度 ≤1s，与 AVSession 共用一道闸」）：
   原来 `syncCard()` 无节流，进度路径（歌词行变化 / 无歌词 5s）与元数据路径共用一个函数。
   改为 `syncCard(force = true)` + `CARD_PUSH_MIN_INTERVAL_MS = 1000` 地板：
   - 进度路径（歌词行变化、无歌词 5s 补推）传 `force=false` → 受 1s 地板限制；
   - **换歌 / 换封面 / 歌词到达 / 播放暂停态变化 / 主题切换**一律 `force=true` 立刻推（语义必须即时）。
