## 操作沉淀：如何从 SSH 拉起 DevEco 模拟器（宿主机）

1. 模拟器数据在 **Administrator 账户**下，`rootwin` 直接 `Emulator.exe -list` 是空的：
   `C:\Users\Administrator\AppData\Local\Huawei\Emulator\deployed\Mate 90 Pro`（实例）
   `C:\Users\Administrator\AppData\Local\Huawei\Sdk`（system-image）
2. 先接受许可（否则 start 会停在 `Please agree to the agreement first`）：
   `Emulator.exe -license accept`
3. `Start-Process` 起的进程会随 SSH 会话被回收 → 用 **WMI 分离**创建：
   `Invoke-CimMethod -ClassName Win32_Process -MethodName Create -Arguments @{CommandLine='...'}`
4. 实例名含空格，必须整体加引号传参（否则报 `Invalid command: please attach - or -- before the option!`）：
   `-start "Mate 90 Pro" -instancePath "...deployed" -imageRoot "...Sdk" -noWindow`
5. 冷启动约 2–3 分钟后 `hdc list targets` 出现 `127.0.0.1:5555`。
