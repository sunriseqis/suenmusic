## 用户反馈四修复（全部已回执 ✅）

1. **反馈4 冷启动续播队列错乱**：根因 = `MediaPlayerCore.setQueue` 里 `bumpQueue()`（持久化）跑在 index 赋值**前**，把「新队列 + 旧下标」写进了偏好。修法：`bumpQueue()` 挪到 index 赋值之后（`core/MediaPlayerCore.ets`）。
2. **反馈3 切歌封面不更新**：根因 = formImages 复用固定 key `suen_cover_img`，官方文档要求刷新图片必须换新 key（示例 `'file' + Date.now()`）。修法：版本化 key `suen_cover_<时间戳>`——`NowPlaying.ets` 新增 `CARD_COVER_KEY_PREFIX`，`attachCover` 落盘成功时生成 `coverKey` 进快照，三条推卡路径（syncCard / NowPlaying 推卡 / EntryAbility pushSnapshotToCards）统一走 `buildFormBindingObject` 的 `formImages`。顺带修死码：`AVSessionManager.lastMetaAssetId` 从未赋值，改为 `setAVMetadata` 成功后才赋值。旧持久化快照缺 coverKey → `readSnapshotSync` 归一为 `''`，下次推卡自愈。
3. **反馈2 2x4 歌名截断**：歌名 `maxLines(2)` + `lineHeight(16)`（`forms/SuenFormCard.ets`）。
4. **反馈1 2x4 移除红心**：删收藏按钮 + `isFav`/btnIcon/btnColor favorite 分支 + `@LocalStorageProp('suen_favorite')`。**数据通道保留**（payload 键 `suen_favorite`、`updateFavorite`），可逆；`card_heart`/`card_heart_filled` 资源仍被 FavoritesPage/TrackItem 使用勿删。

## 冷启动闪登录页（第三轮反馈，本轮新修，待回执）

现象：冷启动闪过一次登录界面再进主界面。根因：`NativeRoot.build()` 首帧按 `@StorageLink(K_LOGGED_IN)` 初始值 `false` 渲染 `LoginPage`，而登录态要等 `AppState.bootstrap()`（preferences + `api.me()` 网络往返）异步完成才翻正。修法：
- `AppState.ets` 新增 `K_BOOTSTRAP_DONE`（AppStorage 通道）；`bootstrap()` 拆 `bootstrapInner`，外层 try/catch/finally，**finally 里无条件置位**（防 api.init 抛错卡死启动屏）。
- `NativeRoot.ets` 加 `@StorageLink(K_BOOTSTRAP_DONE)`，build() 三分支：`!bootstrapDone` → 中性启动占位（Tokens.bg + 居中 80vp app_icon），`!loggedIn` → LoginPage，否则主界面。
- 未登录路径占位近瞬时（prefs 本地读）；已登录 LAN 路径 ≈ me() 一个来回后直接进主界面；离线带令牌沿用既有乐观登录（占位时长 = me() 超时，语义上比登录页挂着更 truthful）。
