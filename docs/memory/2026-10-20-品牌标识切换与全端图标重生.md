## 三、字标：自绘 → 字体

WordMark 原本是 09-12 给旧音浪配的圆头描边 SVG。先自绘了折角版
（`web/scripts/gen-wordmark-angular.py`：骨架折线 → stroker 生成实心多边形，
45° 切角端头 + 尖接转角），**中间把 S 画反了**（见教训），用户最终拍板：
**直接用 `Gunstop.ttf`**。

现状：

```
web/public/fonts/Gunstop.ttf     21KB 全量托管，@font-face 在 styles/fonts.css
WordMark.vue                     SVG → 文本排版（font-family Gunstop，drop-shadow 拟物不变）
BrandLockup                      word 参数高度改字号：侧栏 md 18 / 登录页 lg 21
```

Gunstop（Drizy Studio Demo）本身是切角工业风，与 MarkBold 同语言；仅 114 字形，
**只用于品牌字标这一处文本**。自绘生成器保留未删，`docs/icon/wordmark-*.svg`
暂仍是自绘折角版（需要矢量化字标时再同步）。

## 四、教训

1. **删预览页/临时页必须查引用**：`/design` 一删，新 logo 组件直接成孤儿。
   预览页承载的资产要么接进真实界面，要么在删除提交里显式处理。
2. **字母拓扑不能凭感觉**：S 画成「顶杠+右竖+斜切↙+底杠」就是 Z/2 的拓扑；
   正确 S 是上竖在左、下竖在右。生成器里已加警示注释。
3. **用户说"重做过"的东西先去会话记录里找**：transcript 可 grep，比问快。
