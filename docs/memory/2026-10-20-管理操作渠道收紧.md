# 管理操作渠道收紧：客户端只读，Web 面板才可配（2026-10-20）

> **归档类型**：产品边界实施记录（渠道闸 + 设置页重新门禁）  
> **索引**：`docs/memory/MEMORY.md`

---

## 一、起因

用户指出之前的约定被违反：「客户端无法修改服务器配置（模型分配、模型添加、
登录 cookie、下载数据库备份等），服务端才可操作」。回查 docs，约定确实躺着
两份（10-18 设置页边界文档、10-20 回归服务端方案），但实施漂成了
「移动端不拦」：`requireAdmin` 只查 role 不查渠道，设置页四个管理区块只判
role 不判平台——管理员的 Bearer 令牌从原生壳打进来全放行。

## 二、决策（用户逐条确认）

```
① 双层硬     服务端渠道闸 + UI「仅 Web 面板」判断，两者都做
② AI 分配    客户端**保留**分配（10-18 文档原样，不收口）；
             模型增删改/测试 = Web 面板管理员；分配对任何登录用户开放
              （文档未对分配设角色；如需收紧成仅管理员，在
               updateAiAssignment 加 role 判断即可）
③ credentials 删干净：路由 + api/sources.ts + session.ts 三处调用 + 缓存键
              （直连模式已废止，该接口是死代码还把凭据落设备）
④ 原生壳     锁掉的区块整块隐藏，不放提示
⑤ 运行情况   客户端彻底隐藏，含管理员；Web 面板行为不变
```

⚠️ 用户 08:20 的消息曾把「模型分配」列进服务端专属，与 ② 冲突；
按 ② 执行（客户端有分配），已向用户明示。

## 三、实施

**服务端**
- `http/require-auth.ts` 新增 `requireWebAdmin`：Bearer → 403「管理操作仅限
  Web 面板执行」，只认 cookie 会话 + admin，CSRF 照旧
- 应用到：`routes/admin.ts` 全部 8 条；`routes/ai-settings.ts` 的
  models 三条；`routes/bilibili.ts` / `netease.ts` 的扫码/轮询/退出
  （状态读取 `GET /account` 保持 requireUser）
- 拆分分配接口：`GET|PATCH /api/ai/assignment`（requireUser，任何登录用户
  任何渠道）；`updateAiAssignment` 校验 id 存在，切指派不打网络
- `POST /api/ai/models` 缺省分配字段时**保留当前指派**；指派 id 不在新清单
  （模型被删）时归一化到第一个模型
- 删除 `routes/sources.ts`（/api/sources/credentials）

**Web**
- `native/update.ts` 新增 `isWebPanel = !isHarmony && !Capacitor.isNativePlatform()`
  （鸿蒙不走 Capacitor，必须显式排除，否则被当成 Web）
- 设置页：新增「AI 分配」区块（`AiAssignment.vue`，改动即存）；
  「AI 模型」「账号管理」「数据维护」加 `isWebPanel && admin`；
  音源授权改为全员只读 + 按钮限 Web 管理员；运行情况 `v-if="isWebPanel"`
- `AdminAiModels.vue` 去掉分配 UI（挪去 AiAssignment），纯 CRUD

**测试**（全套件绿：db 128 / api 212 / cli 18 / business 276 / plaza 57 /
resolver 63）
- api/business 测试 helper 支持 cookie 通道（含 CSRF 头）；admin 调用全改 cookie
- 新增覆盖：管理员 Bearer 打 `/api/admin/users`、`/api/ai/models`、
  `/api/ai/models/test` 一律 403；cookie 同人放行；分配接口 Bearer 200、
  视图只有 id/name 不带 Key 脱敏值；非法指派 id 400；credentials 404

## 三点五、当日修订：AI 分配收回管理员（用户晚拍板）

用户原话：「AI分配web端管理员可改，其他用户不可改不可见」。这与当日早些时候
「客户端只做分配」的回答冲突，以晚拍板为准：

```
删除    GET|PATCH /api/ai/assignment（曾按②开放给任何登录用户）
        services/ai-client.ts 的 updateAiAssignment / getAiAssignmentView
        web 侧 AiAssignment.vue 与「AI 分配」区块、api/ai.ts 两个调用、类型
回归    分配下拉回到 AdminAiModels.vue，随 POST /api/ai/models 保存
        （该路由本就支持缺省分配字段 = 保留当前指派，见「实施」节）
测试    [8c] 改为断言 assignment 接口 404、Bearer 打 models 403、
        cookie 保存缺省分配字段时指派保留
```
