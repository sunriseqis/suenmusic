## 一、问题与根因

- 用户反馈：播放页播放键上方也有一条横线（上一轮已修掉迷你条那条）。
- 根因：`WebIconButton.build()` 里还留着一条 1vp 顶沿内高光（`Row().height(Dim.hairline).width('100%')` + `Tokens.hi`），
  只在 `chromeKind !== PLAIN` 时才画 —— 全端只剩两个非 PLAIN 键：①播放页主播放键（GRADIENT，60vp）②搜索页搜索键（GRADIENT，44vp）。
- 处理：整块删除（GRADIENT 键的厚度感由 `linearGradient` 自身提供）。连同上一轮删掉的 `NativeRoot.barSheen()`，本端不再有键顶高光横线。

## 四、教训（已吃一次亏）

- `output/*.hap` 是交付副本，编译产物在 `hw/entry/build/default/outputs/default/entry-default-unsigned.hap`。
  本次只编译没刷新 output，scp 传过去的是上一版，在模拟器上反复验证失败白折腾一轮。
  **铁律：scp/交付前先 cp 编译产物到 output 并核 md5**（本次证据：旧 output md5 789270f… vs 新编译 df9fedee…）。
- `hdc install -r` 对同 versionCode 会覆盖，装完必须 `aa force-stop` 再 `aa start`，否则 dump 到旧进程界面。
- 判断修没修好用 dump 的子节点数量/类型 + 节点背景色，比截图可靠，也不需要识图能力。
