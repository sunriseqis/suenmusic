# 2026-10-26 酷狗音源正式接入（音源链 + 搜索端点）

承接 `2026-10-26-后端优化与酷狗接入.md`。提交 `df4ec7e`（beta）。

## 音源链现状

```
手动锚定（最高优先，永久）
  ↓ 未锚定
网易云（免费，cookie 有效）
  ↓ 未命中
酷狗（概念版 VIP，FLAC/320/128 按权益选档）
  ↓ 未命中 / 无凭据 / 全档需 VIP
B 站（最终兜底，自带冷却闸）
```

hw 端零改动：resolve 下发的 directUrl/directHeaders 音源无关，hw 已按直链优先+代理兜底工作。

## 新文件/改动

- `sources/kugou/stream.ts`（新增 ~210 行）：`resolveKugouSource` 实现 ResolveResult 契约。
  三步：搜索（概念版盐）→ privilege/lite 逐档权益（relate_goods）→ /v6/priv_url 取直链。
  匹配闸：规范化歌名互含 + 时长差 ≤5s（宁缺勿错配）。
  无凭据 → below_threshold（不进链）。失败归固定 reason 枚举。
- `sources/bilibili/stream.ts`：`source` 联合类型扩 `kugou`（ResolveResult + fetchAudioStream 选项）。
- `services/resolver.ts`：网易云未命中后插酷狗段。
- `routes/catalog.ts`：`GET /api/search/kugou`（独立探索端点）。

## 验证

- 单元级：`resolveKugouSource({name:'突然好想你',artists:['五月天']})` → **FLAC@871kbps 直链**（酷狗命中日志）；
- 负路径：`叱咤红人` 酷狗无匹配 → 正确落 B 站（ok:true source:bilibili）；
- 接口级：`/api/search/kugou?q=李荣浩 不老的父亲` → 3 首（kg_ id）。

## id 约定的边界（重要）

酷狗曲目 id = `kg_<albumAudioId>`，与全站 `qq_<songmid>` 路由约定**不同**。
- 取流/解析：`resolveKugouSource` 在服务端内部完成，**不暴露 kg_ id 给客户端**——
  客户端永远拿 `qq_xxx` + streamUrl/directUrl，无感知；
- 搜索：独立端点 /api/search/kugou 先行（探索用），**不混入 /api/search**——
  混入需要三端改 id 语义（hw/ios/web 的路由、跳转、详情页全按 qq_ 硬编码），风险大；
- 未来做 id 双向映射（kg_ ↔ qq_ 锚点表）后再聚合进主搜索。

## 元数据兜底的边界

「QQ 搜不到 → 酷狗补元数据」这件事**没有做进单曲回源**（catalog.ts:314）——
回源请求只有 trackId 没有关键词，无法搜酷狗。真正的元数据兜底在：
1. 每日推荐 payload 快照（完整 Track 随 payload 走，已实现）；
2. 搜索聚合（待 id 映射）。
