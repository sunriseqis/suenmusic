# 2026-10-26 直链通道落地与鸿蒙模拟器验收

## 一、为什么要做直链

历史决策文档 `2026-10-20-终止直连回归服务端.md` 终止的是「客户端自己解析直链」（签名跑在前端 JS，锁屏即失去解析能力），
不是「服务端解析好直链下发给设备」。两者性质不同：

| 当年失败的四条原因 | 对「服务端下发直链」是否成立 |
|---|---|
| iOS 后台挂起 WKWebView JS | 不成立（解析在服务端） |
| 端侧预填受 -412 风控 | 不成立（解析在服务端，按需 + 缓存） |
| 本地优先数据孤岛 | 不成立（数据已收敛服务端） |
| 反爬规则变化要重新发版 | 部分成立（客户端只需处理 403 回退） |

代理的代价是每次播放都占服务端上行带宽（还被 40KB/s 限速坑过）；直链把容量模型从「按带宽」变成「按解析 QPS」。

## 二、服务端实现（server/src/routes/resolve.ts）

GET /api/resolve/:trackId 在原有 streamUrl 之外新增：

- directUrl：裸 CDN 地址（来自 play_sources.audioUrl，缓存命中也有）
- directHeaders：B 站 = User-Agent + Referer；网易云 = 仅 User-Agent
- directExpiresInSec：直链剩余有效期（与音源缓存同口径）

要点：

- 开关 SUENMUSIC_DIRECT_LINK=off 一键回退纯代理（无需发版）；
- 代理 streamUrl 永不删，是 403/过期的兜底通道；
- 头里绝不能带 Cookie：biliHeaders() 那份含 SESSDATA/DedeUserID（登录凭据），CDN 播放只需要 Referer。第一版整份下发，发现后立刻改掉。

## 三、鸿蒙端实现（hw/entry/src/main/ets/core/MediaPlayerCore.ets）

- 直链优先：media.createMediaSourceWithUrl(url, headers) + p.setMediaSource(ms)（SDK 确认 API 12/13 起可用）；
- 解析超时 800ms（服务端命中缓存通常 <50ms，不拖慢起播）；
- 失败自动回退：直链装载/播放出错 → 清直链标记 → 用 /api/stream 重载一次；回退状态按曲目 id 重置，不会无限循环；
- ArkTS 约束：对象字面量不能当类型 → 新增 DirectLink 接口。

## 四、验证（HarmonyOS 模拟器，非纸面）

环境：Windows 10（rootwin@100.66.45.14）上的 DevEco 模拟器，hdc 目标 127.0.0.1:5555。
可复用的驱动方式：

1. hdc install <hap>
2. hdc shell aa start -b com.suenmusic.app -a EntryAbility
3. hdc shell uitest dumpLayout 取坐标
4. uitest uiInput click x y
5. hdc shell hilog -x 取日志

实测输出：

```
install bundle successfully
SuenMusic_State: 恢复登录成功: suenqi
SuenMusic_Player: 直链装载 track=qq_003UQwPW3OPxBy exp=1799998ms      ← 走直链（约 30 分钟有效期）
SuenMusic_AVSession: state=2, elapsed=12204 → 17302                  ← 时间轴推进，确实在播
服务端 /api/stream 这期间零请求                                       ← 音频不再经过服务端
```

另外用 curl 单独验证：UA + Referer 直取 CDN → 206 / 1024B / video/mp4，且头里无 Cookie。

## 五、遗留

1. iOS 未接（Mac 构建机失联）：改法最简单 —— 把 AudioCacheStore 本地代理的上游从 /api/stream 换成 directUrl + 头，磁盘缓存/断流续拉/起播加速全部保留，且不需要 AVURLAssetHTTPHeaderFieldsKey 这类非公开用法；
2. 到期前主动重解析未做：目前靠「播放失败 → 回退代理」，长播（>30 分钟）体验更差，应改为到期前 X 分钟静默重解析；
3. Android 封仓，不做；
4. 代理与限速代码保留（兜底路径需要），但主链路已绕开。
