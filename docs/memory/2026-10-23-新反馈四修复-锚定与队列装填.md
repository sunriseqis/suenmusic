## ① 修正音源 / 手动锚定（web AnchorDialog 同口径）

### 接口层（`core/Models.ets` + `core/APIClient.ets`）

- Models 增 6 接口：`BiliCandidate`（含 `score/durationDiff/pic/previewUrl`）、`AnchorTrackMeta`、`BiliCandidatesResult`、`AnchorBody`、`TrackAnchorInfo`、`TrackAnchorReply` —— 形状照抄 `web/src/api/playback.ts`（注意 web 已比旧分析多出 `durationDiff`/`pic` 字段）。
- APIClient 增 4 方法：
  - `biliCandidates(trackId, keyword)` GET `/api/tracks/:id/bili-candidates?keyword=`（20s 超时）
  - `anchorTrack(trackId, body)` POST `/api/tracks/:id/anchor`
  - `fetchTrackAnchor(trackId)` GET `/api/tracks/:id/anchor`（`{anchor: TrackAnchorInfo|null}`）
  - `unanchorTrack(trackId)` DELETE 同端点

### 播放页（`pages/PlayerPage.ets`，新 'anchor' 浮层层级）

- `K_PLAYER_SHEET` 扩值 `'anchor'`（NativeRoot onBackPress 值无关处理，自动接线返回手势）。
- 更多菜单（对齐 web more-menu 顺序）：**当前音源**静态行（`sourceLabel()`：已锚定→'B 站 · 已锚定'，否则'未解析'）→ 歌手 → 专辑 → **修正音源**行（→ `openAnchorSheet()`）；旧回退文案「暂无歌手/专辑信息」删除。
- `anchorSheet()` 居中弹窗：标题/曲名/关闭 → 当前音源行 → 已有锚点块（回显 `title||bvid · author` + 解除钮）→ 搜索行（NeuInput 关键词默认「歌名 + 主歌手」+ 搜索钮，打开自动搜一轮）→ 说明文字（风控/空结果）→ 原版参照卡（歌名/歌手·专辑/参考时长）→ 候选列表（标题/UP/时长/置信分/试听+锚定钮）。
- 候选时长差异警告：`|durationDiff| > 20s` 显示 accent 色「时长与曲目差得多（差 N 秒），可能不是同一版本」（web `durationMismatch` 同阈值同口径；服务端给的 durationDiff 是绝对值，不声称方向）。
- **试听**：独立 `media.AVPlayer` 单实例（`previewPlayer`），`previewUrl` 拼 `getBaseUrl()`（服务端相对路径带短期令牌）；换条即换 URI、播完/失败自动收、关弹窗/切歌/锚定/搜索即停 —— **完全不动主播放内核**。创建竞态守卫：`createAVPlayer()` 在途时再点别条，新实例按 `previewingBvid` 比对弃用。
- **锚定后重载**（web `retryAfterAnchor` 同坑处理）：`anchorTrack` 成功 → toast「已锚定，开始播放」→ **清旧音源缓存**（`OfflineCache.setProtected('')` + `remove(trackId)`——旧音源字节以曲目 id 缓存、fd:// 优先，不清会直接盖住新锚点，web 原生端同款踩坑）→ `MediaPlayerCore.retryCurrent()`（服务端锚定时已清解析缓存，重装即走新锚点）→ 重查锚点回显。**播放状态机骨架零改动**（retryCurrent 是既有 T4 方法）。
- 解除锚定：DELETE 后清 `anchorInfo` + toast「已解除锚定，该曲目回到自动匹配」。
- 切歌（`onTrackChanged`）：'anchor' 层随曲收起（同 dislike/more）、停试听、清候选/参照/说明状态、重查新曲锚点；`aboutToDisappear` 停试听。

### 与 web 的差异（记档）

> ⚠️ **本节的「记档」= 执行方单方取舍，未获用户裁定**（2026-10-23 用户澄清「这些裁决不是我做的」）。
> 复盘时不得当作「用户已裁定不补」；开放/待拍板口径见 `2026-10-23-记忆纠错-差异记档不等于用户裁定.md`。

- **解析失败自动弹锚窗不做**：web 播放失败 noSkip 分支会自动置 `anchorCandidate` 弹窗；hw 播放失败总是自动跳下一首（既有内核语义），锚窗只从更多菜单手动进。
- **当前音源标签降级**：web 有 `currentSource` 逐曲追踪（播放中显示 '网易云'/'B 站'）；hw 无该通道，只区分「已锚定 / 未解析」，播放中的源类型不显示。
- web 弹窗挂 App.vue 全局（播放条/全屏页共用）；hw 挂 PlayerPage 层级内。

## ② 队列装填不满修复

- **根因**：歌手页 `playAt` 只装 `this.tracks`（=已加载批次，首批准 50 首）；toplist(200)/歌单/专辑本就全量，不受影响。收藏页同病（`playAt` 只装已加载页）。
- `pages/CollectionPage.ets`：增 `ensureAllSongsLoaded()`（循环 `loadMoreSongs()` 直到 `!songsHasMore`，无推进即退防空转）；`playAt` 歌手路径先装填再 `setQueue`（tracks 只追加，点中下标不变）；`queueFilling` 状态防重复触发 + 播放全部钮文案切「装载中…」。
- `pages/FavoritesPage.ets`：`playAt` 前 `!reachedEnd` 先 `ensureAllLoaded()`；顺带修 `ensureAllLoaded` 空转隐患（页脚 `loadingMore` 在途时原循环会忙转，加 120ms 等待让位）。
- 语义对齐：web `playQueue` 装的是**已装载全集**，hw 现在同口径（歌手页上限仍 MAX_BATCH×50=500，与 web 分批上限一致）。

## ③ 五键错位修复

`bottomFoot` 五键：模式翼/上一首/下一首/队列翼的裸 `SymbolGlyph` 全部外包 `Row` 容器 `width/height = touchMin` + `justifyContent(Center)/alignItems(Center)`；按压缩放/onTouch/accessibility/onClick 上移到容器。播放圆钮本就是容器不受影响。**根因记录**：`constraintSize(minWidth/minHeight)` 只扩布局盒，字形绘制钉在盒左上，不居中。

## ④ 歌词 peek 染色对齐 web

`.peek-line.on` = `var(--accent)` 13px Medium opacity 1；非当前行 = t2 12px opacity .5。hw 对应改：active → `Tokens.accent + fsBody(13) + Medium + opacity 1`；inactive → `text2 + fsMinor(12) + opacity 0.5`。
