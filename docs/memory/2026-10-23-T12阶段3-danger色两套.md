# 2026-10-23 T12 阶段 3（一）：danger 危险色进 Tokens，按主题分两套

## 背景

浅色对齐 web 时发现：web 的危险色**不是 CSS 变量**，而是散落在组件里的字面量 + 一条浅色覆盖：
`NeuButton.vue` → `.v-danger { color: #d4564a }`，`:root[data-theme='light'] .v-danger { color: #a8322a }`。
hw 此前统一写死 `#E5484D`（lint 唯一豁免色），在浅色下偏亮、且与 web 不一致。

## 改动

- 生成器新增 `EXTRA_PALETTE = {'danger': ('#D4564A', '#A8322A')}`（非 CSS 派生，注释写明出处 web `.v-danger`），
  随其余令牌一起进 `Tokens.danger` 与两份 `color.json` 的 `t_danger`。
- 全端 14 处 `'#E5484D'` → `Tokens.danger`（DislikeDialog / WebButtons / CollectionPage / DailyPage /
  FavoritesPage / HomePage / LoginPage / LyricView / PlayerPage ×2 / SearchPage ×2 / ServerListPage）。
- 收藏红底 `#8A1F18` + `#FFDAD6` **保持字面量**：web `TrackRow.vue` / `QueuePanel.vue` 两套主题同值，无需分主题。

## 校验

- `python3 scripts/gen-brand-tokens.py` → base `t_danger=#A8322A`（浅）/ dark `t_danger=#D4564A`（深）
- check-arkts：**ERROR 0 / WARN 4**（余下 4 条全是上述收藏红底与一个 `#00000000`，均属 web 同值/透明色）
- BUILD SUCCESSFUL；已装模拟器（md5 5dad4f5f37f46e6269e7f974b03b744d）
