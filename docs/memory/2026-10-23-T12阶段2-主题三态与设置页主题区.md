# 2026-10-23 T12 阶段 2：主题三态 + 设置页主题区（base 切浅色）

## 实现

- 新 `common/Theme.ets`：三态 `system / light / dark`（与 web `stores/ui.ts` 同值同序），
  用 `ApplicationContext.setColorMode(...)` 通知系统用哪套资源（`COLOR_MODE_NOT_SET` / `LIGHT` / `DARK`），
  选择持久化在 preferences（`app_theme.theme_mode`），并写到 `AppStorage['theme_mode']` 供 UI 读。
- `EntryAbility.onCreate` 里 `Theme.init(this.context)`：**先应用持久化主题再加载窗口内容**，避免闪一次系统主题。
- 设置页「本机」新增 **主题** 分区：`NeuTabs` 三段（跟随系统 / 浅色 / 深色），选完 `Theme.setMode` + toast。
- 生成器 `EMIT_LIGHT_IN_BASE = True`：`resources/base` 改浅色（`t_bg=#F2F0EA`），`resources/dark` 仍是深色。
