## 编译坑（首批全量编译暴露 14 错，全部修复）

1. **`@Event onClick` 与基类 `CommonMethod.onClick` 方法同名冲突**（"not assignable to the same property in base type CustomComponent"）——@Event 改名 `onTap`，14 个页面 52 处调用点同步替换。**禁止改回 onClick**
2. **全局 @Builder 调用不能链属性**（返回 void）：TrackItem dislike 双钮外包 Row 承载触摸区；PlayerPage dislikePop 的 offset/margin 移入根节点
3. `requestInStream` 的 Promise 解析值 = HTTP 状态码（number），不是 HttpResponse
4. Linear 进度条无 `trackColor`（ProgressAttribute 不含）；条粗细走 `.style({strokeWidth})`
5. `area.width` 是 Length（string|number|Resource），赋 number 需 typeof 收窄
