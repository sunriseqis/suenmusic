**音质**：只有标准档（实测 ~89kbps）。`/tracker/v5/url` 逐档实测：

```
flac → status=2  url=NO
high → status=2  url=NO
320  → status=2  url=NO
128  → status=1  url=YES (timeLength=265)
```

试过加真实 `album_id`、`vip=1`、`priv_vip_type=6`，320 依旧 `status=2`。
**用户裁定：音质问题不追**，先落客户端收尾。

**顺带修掉一个会挡住验证的坑**：`r_register_dev` 回 `20006`（签名不兼容）时原逻辑退回 `dfid='-'`，
网关会把请求当匿名 → 只给试听片段。改为参考实现策略：不强制注册，随机 24 位 dfid 并持久化到 `kugou.dfid`（`634d4e3`）。

## 三、签到：空缺（明确留白）

按用户裁定，**签到协议不写进本项目**（广告播放上报 / 领取请求属平台行为，由账号本人自建工具负责）。

因此以下留空，不实现：
- 每日签到请求（`/youth/...`、ad play report）
- 签到态字段（`checkedIn`）、签到调度、签到成功后的会员刷新

客户端与文档里**不出现**假的签到状态；设置页只展示真实登录态四态
（未登录 / 登录已失效 / 已登录·会员到期 / 已登录·会员有效）。

如果以后要接，接口位已经留好：
```
GET  /api/admin/kugou/status          现有：四态登录态（label 由服务端下发）
POST /api/admin/kugou/credentials/import   现有：外部登录态灌入（支持直接粘 cookie 串）
```
