# 2026-10-24 桌面卡片跟随设置内主题 + 滚动条全局关闭

## 1. 卡片深浅跟随「设置里的主题」（用户裁定，覆盖此前「卡片只跟系统」的记档）

问题：卡片原先用 `$r('app.color.card_*')` 资源 —— 那套只跟**系统**深浅，所以设置里切成深色时卡片仍是浅色卡。
用户裁定：**浅色 → 浅色卡，深色 → 深色卡，自动 → 跟系统**。

实现（卡片是 FormExtension 独立进程，拿不到 AppStorage，也不能靠 setColorMode）：
- payload 新增 `suen_dark`（'true'/'false'）：`toCardPayload`/`buildFormBindingObject` 多一个 `dark` 参数；
  调用方三处各算：EntryAbility 用 `Theme.darkFor(this.context, 系统是否深色)`、AVSessionManager 用 `Theme.darkNow()`、
  SuenFormAbility 用 `Theme.darkFor(this.context, Theme.isSystemDark(this.context.config.colorMode))`。
- `Theme` 新增：`K_SYSTEM_DARK`、`syncSystemDark()`（EntryAbility.onConfigurationUpdate 更新）、
  `darkNow()`（意图 + 系统态）、`darkFor(ctx, systemDark)`（读 preferences 的持久化选择）、`isSystemDark(cm)`。
- 卡片 `SuenFormCard`：加 `@LocalStorageProp('suen_dark')`，8 个色板方法（`cBg/cT1/cT2/cAccent/cAccentText/cAccentOn/cWell/cLine`）
  按深浅返回与 resources/base|dark 同值的字面量；**25 处 `$r('app.color.card_*')` 全部替换**。
- 切主题立刻重推卡片：`Theme.setMode` 广播 `AppStorage['card_refresh']++` → NativeRoot `@Watch` → `AVSessionManager.refreshCard()`（新公开方法）。

实测（模拟器，桌面上有 2 张卡片）：
```
00:11:28 主题模式=light   → 已刷新 2 张桌面卡片
00:11:34 主题模式=dark    → 已刷新 2 张桌面卡片
00:11:42 主题模式=system  → 已刷新 2 张桌面卡片
00:11:43 主题模式=light   → 已刷新 2 张桌面卡片
```
桌面 dump 复核：卡片背景 `#FFFAF8F3`(card_bg 浅) / `#FFEDEAE2`(card_well 浅) / `#1F1B1916`(card_line 浅) → **浅色卡生效**。
