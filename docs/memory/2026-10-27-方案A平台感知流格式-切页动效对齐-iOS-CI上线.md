## 一、方案 A：平台感知取流与 320k MP3 优先（iOS 原生播放破局）

### 1. 现象与底层根因
- **现象**：本地开发环境 iOS 模拟器可正常播放音乐，但连接生产端（飞牛 `8904`，已配置酷狗概念版 SVIP）后，点击播放进度条一直卡在 `0:00`，不出声也不切歌。
- **根因分析**：
  1. **AVPlayer 格式硬限制**：生产端已激活酷狗 SVIP，点播默认返回最高音质 `flac`（裸 `.flac`，`audio/x-flac`）。Apple iOS 的 `AVFoundation / CoreMedia` 框架**原生不支持 HTTP 裸 FLAC 文件的渐进式流式播放**，必须封装为 HLS 或使用自定义 PCM 解码器。
  2. **酷狗 tracker 参数隐患**：原取流参数硬编码了 `need_ogg: '1'`，导致请求 320k 时酷狗返回了 `audio/ogg`（Ogg Vorbis 容器），iOS 同样无法原生解码。
  3. **本地开发端此前能播的原因**：本地开发环境无酷狗 VIP，自动回落至普通 128k MP3（`audio/mpeg`），因此避开了格式问题。

### 2. 方案 A 实现与双轨缓存
- **平台感知识别**：新增 `server/src/http/platform.ts` 的 `isIosClient(req)`，结合请求头 `X-Platform: ios`、User-Agent（含 `suenmusic-ios`、`iphone`、`ipad`、`cfnetwork` 等）以及参数 `platform=ios` / `format=mp3` 识别 iOS 客户端。
- **音源优雅降级**：
  - **酷狗**（`server/src/sources/kugou/stream.ts`）：iOS 请求跳过 `flac` 和 `high`，设置 `need_ogg: '0'`，以 `['320', '128']` 优先获取标准的 320kbps MP3（`audio/mpeg`）。
  - **网易云**（`server/src/sources/netease/source.ts`）：iOS 请求跳过 `lossless`，以 `['exhigh', 'standard']` 优先获取高码率 MP3。
- **双轨缓存隔离**：
  - `server/src/services/resolver.ts`：iOS 请求使用独立的持久化与内存缓存键 `${trackId}:mp3`；
  - 防御性校验 `isFlacUrl()`（覆盖 `.flac`、`quflac`、`.ogg`），遇历史旧缓存自动失效并重走 MP3 链；
  - **Web 与鸿蒙端完全保留最高规格的 FLAC 无损流，双端缓存互不踩踏、互不降级**。
- **端侧协议升级**：
  - `ios/SuenMusic/Net/APIClient.swift`：全请求带 `X-Platform: ios` 与 `User-Agent: SuenMusic-iOS/1.0`；
  - `ios/SuenMusic/Player/AudioCacheStore.swift`：回环代理向服务端请求流携带 `platform=ios`；
  - `ios/SuenMusic/Player/AudioEngine.swift`：直链备用地址携带 `platform=ios`。

### 3. 实测数据
- 本地服务（`http://192.168.89.10:3210`）解析五月天《今夜让我带你高飞远走》（`qq_0021l8uU2eRXT9`）：
  - Web 客户端：返回 `...quflac_...flac`，`Content-Type: audio/x-flac`（FLAC 无损）；
  - iOS 客户端：返回 `...qu320_...mp3`，`Content-Type: audio/mpeg`（9.8MB，标准 ID3 MP3）；
  - Mac 宿主机 AVPlayer 实测：数毫秒内即进入 `readyToPlay`（`duration=246.04s`）。

## 四、iOS CI 接入版本号自动构建

- **工作流配置**：`.github/workflows/build-ios.yml`
  - 命名统一为 `构建发行苹果端`（移除原 `(手动)`）；
  - 触发条件增加 `push.tags: ['v*']` 与 `push.paths: ['VERSION']`，当在版本库给版本打 Tag 或提交更新根目录 `VERSION` 时自动拉起 CI 构建；
  - 剥离原 Capacitor 时代的 Web 打包与同步步骤，纯原生编译，构建时长从 8 分钟压缩至 2 分钟内。
- **构建脚本适配**：`scripts/build-ios.mjs`
  - 移除已废弃的 `syncWeb()` 与 `assertVendor()` 依赖检查，支持纯原生 Xcode 工程（`App.xcodeproj`）Release 构建与打包 unsigned IPA。
- **三端联动**：`.github/workflows/build-harmony.yml` 与 `build-fnos.yml` 亦同步补齐 `paths: ['VERSION']` 触发器，实现「改版本号/打 Tag，全端自动发行」闭环。
