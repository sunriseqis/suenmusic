## ① 迷你播放控件「按钮上方有一条横线」

- 原因：迷你条顶上那条 1vp 顶沿内高光（`NativeRoot.barSheen()`，`Tokens.hi` 6% 白）。
  迷你条本身只有 ~60vp 高，这条线横跨整条上沿、正好压在红心/播放键上方，观感就是一条杂线。
- 处理：**删掉 `barSheen()`（含 builder）**；同时把红心/播放两个图标键从 `CHROME`（panel 底 + 发丝描边 +
  内高光）改成 **`PLAIN`**（灰白透明底、无描边无高光）——与「收起播放页」的箭头键同一套，
  保证按钮周围不再有任何多余横线。

## ② 锚定弹窗（PlayerPage 'anchor' 层）按钮改造

| 位置 | 原 | 现 |
|---|---|---|
| 搜索行 | `WebButton`（琥珀填充 + 文字「搜索」/「搜索中…」） | **`WebIconButton` 放大镜图标**，`boxSize=Dim.touchMin`（比文字钮窄），`PLAIN` 灰白透明底；搜索中字形染 accent |
| 候选行 | `WebButton`（琥珀填充 + 文字「锚定」/「锚定中…」） | **大头针图标 `sys.symbol.pin`**，`PLAIN` 灰白透明底；提交中染 accent 并在 `onTap` 里拦住重复点击 |

- 依据用户原话：「这两类图标不要用强调色打底的按钮，用类似页面关闭向下箭头的灰白透明背景图标」。
- 新图标常量：`WebIconName.PIN`（`WebIcons.ets` → `$r('sys.symbol.pin')`）。
  **符号存在性已核**：SDK `sysResource.js` 里 `pin: 125831547`（与 `magnifyingglass: 125831500` 同段，
  即 `sys.symbol` 段），沿用 T10 教训「sys.symbol 名必须查资源表，不能凭印象」。
