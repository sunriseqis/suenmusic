# 2026-10-23 无音源呈现规格定稿：连播静默跳过（只通知）/ 手动点播只在「正在播放」显示「无音源」

**用户 2026-10-23 定的规格**（原话）：「列表播放报错跳过，页面不显示任何报错信息，只系统通知；
手动点回该曲目，再正在播放的位置显示无音源即可」+「报错不再出现什么取消、重试」。

## 实现

| 场景 | 页面 | 系统通知 | 行为 |
|---|---|---|---|
| 列表连播遇到无音源 | **无任何报错痕迹**（np_error 清空） | 发「《X》…已自动跳过」 | 600ms 后 advance(true) 跳过 |
| 手动点这首歌 | 只在顶栏「正在播放」那行显示 **无音源**（红色） | 不发（人就在页面上） | **停在当前曲不切**；修音源走「更多 → 修正音源」 |
| 连续多首无音源 | 无报错痕迹 | 发「连续多首没有匹配音源」 | 停播 |

- **删掉**播放页底部的错误横幅与「重试 / 跳过」两个按钮（PlayerPage.bottomFoot），避免"报错弹一堆操作"的观感；
  WebButton/NeuBtnVariant 相应导入清理。
- NO_SOURCE_LABEL = '无音源' 常量集中管理文案；settleFailure() 三个分支按场景分别设置 np_error 与通知。
