## 二、图标规格审计（用户要求：逐点对 web 尺寸规范）

### 方法（不需要截图、不需要设备）

`PX_SIZE = { sm:28, md:36, lg:44, xl:60 }`、`ICON_SIZE = { sm:15, md:18, lg:21, xl:26 }`；

hw 侧把全部 `WebIcon(...)` 与 `WebIconButton({ boxSize })` 调用点抓出来逐一比对。

### 结论 A：**按钮档位全部合规**（20 处 `WebIconButton`）

hw 的 `boxSize` 只落在 28 / 36 / 44 / 60 四档，且 `WebIconButton` 的 glyph 自动按档位取
15 / 18 / 21 / 26 —— **与 web 完全一致，没有一处超规格放大**。
（上一轮「图标太大挤占文字」的真实根因是 `WebButton` 宽度塌爆，已修，不是图标尺寸问题。）

唯一**刻意偏离**：播放页收起键 `44`（web `md`=36）——你在前一轮反馈「找不到关闭按钮」，
按 ≥44 触控区加大，保留。
