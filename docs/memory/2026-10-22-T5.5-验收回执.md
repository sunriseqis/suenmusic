## 【⚠️ 规格偏离记录】（2 处，均有据）

1. **新碟一屏张数**：单子写「露出下一张 60-70%」，web ≤767px 实测 `--poster-per-page: 2` **一屏整 2 张不露边** → 按 web 用 `Swiper displayCount(2)`，非 60-70% 露边形态。定性条款裁决。
2. **巅峰榜两列实现**：List 的 ListItem 高度无界，Grid 无 rowsTemplate 会异常 → 弃 Grid，`toplistRows()` 手工行分组 Row（奇数行末卡独占半宽，与 web grid 同构）。

## 【给后端的反馈（第三轮反馈核查结论）】

- **结论：服务端字段分工本就正确，无需改**。`welcomePhrase`（首页欢迎语）与 `greeting`（每日页导语）由 `ai-welcome.ts` 同一 prompt 分开生成、禁重复（「两句话不要重复」）；「混淆」是客户端渲染问题（已修）。
- `welcomePhrase` 合规：prompt 6~20 汉字 + 句末标点 + clamp 24，首页单行预算约 27 字（13fp）→ **单行显示无溢出风险**。
- 重申两条（低优先）：① 生成后可加一次 welcomePhrase/greeting 去重校验（prompt 已要求，兜底而已）；② welcomePhrase 保持纯欢迎口吻、禁策展词（prompt 已列负例，维持即可）。
