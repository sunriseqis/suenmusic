# 2026-10-25 iOS 首次真编译通过 + 无图像环境下的 OCR 验证链路

## 一、编译（mac：suenqideimac.lan / macOS 26.7 / Xcode 26.5 / iOS 26.5 模拟器）

```
tar czf - ios | ssh suenqi@suenqideimac.lan 'mkdir -p ~/suenmusic && tar xzf - -C ~/suenmusic'
cd ~/suenmusic && xcodebuild -project ios/App/App.xcodeproj -target App \
  -sdk iphonesimulator -configuration Debug CODE_SIGNING_ALLOWED=NO build
```

**首次编译就暴露 3 个真实错误**（此前 24 个文件从未编译过）：

| 错误 | 根因 | 修法 |
|---|---|---|
| `invalid redeclaration of 'EmptyReply'` | 我两次编辑各加了一个 | 删掉重复 |
| `ForEach` 要求 `TrackArtist: Identifiable` | 模型只有 Codable/Hashable | 补 Identifiable |
| `cannot find 'Insecure' in scope`（AudioEngine）| `Insecure.SHA1` 是 CryptoKit 的，文件缺 `import CryptoKit` | 补导入 |

修完 → **BUILD SUCCEEDED**。

## 二、装机 + 数据注入（无键盘输入也能进主页）

```
xcrun simctl boot "iPhone 17"
xcrun simctl install booted ios/App/build/Debug-iphonesimulator/App.app
# 绕过登录：把服务端 refreshToken 直接写进 app 的 UserDefaults
xcrun simctl spawn booted defaults write com.suenmusic.app suenmusic.refreshToken -string <token>
xcrun simctl spawn booted defaults write com.suenmusic.app suenmusic.baseUrl -string http://192.168.89.10:3210
xcrun simctl launch booted com.suenmusic.app
```

// NSImage → CGImage → VNRecognizeTextRequest(zh-Hans, accurate) → 逐行打印 [y=.. x=..] 文字

运行：`swift /tmp/ocr.swift /tmp/x.png`（mac 自带 swift，无需装东西）。

## 五、DEBUG-only 界面导航钩子（为无触摸环境而加）
