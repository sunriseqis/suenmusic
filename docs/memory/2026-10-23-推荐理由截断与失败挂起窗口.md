## ② 「弹了重试/跳过，不到 1 秒又开始播同一首」—— 客户端，已修

用户实测：专属页两首都一样，系统通知也弹了，然后瞬间恢复播放。

根因（两件事叠在一起）：
1. **报得太早**：AVPlayer 对 5xx 会自行重试；专属页服务端首帧 503（解析尚未就绪）、重试后约 1s 内就播起来。
   我们一失败就立刻 `np_error` + 发通知 → 观感「错误闪一下又恢复」。
2. **`pendingAutoplay` 没清**：`fail()` 只置 `wantPlay=false`，AVPlayer 随后一次迟到的 `prepared` 事件
   仍会走 `if (pendingAutoplay) player.play()` → 歌又被播起来。

修法（`MediaPlayerCore`）：
- 新增 **`FAIL_GRACE_MS = 2500` 挂起窗口**：失败先不报错、不发通知，只挂计时器；
- 窗口内 `stateChange('playing')` → 撤销计时器 + `failHandled=false` + 清 `np_error`（**静默自愈，不打扰**）；
- 窗口到期仍未播 → `settleFailure()`：**清 `pendingAutoplay`**、停长时任务、写 `np_error`、发系统通知、
  **停在当前曲不切歌**；播放页错误行给「重试 / 跳过」，「更多 → 修正音源」可就地锚定；
- `loadCurrent()` 开头也撤销挂起（重试/跳过/锚定后重装同一条路径）。
