### 卡片/播控三问题修复
1. **冷启动续播**：`MediaPlayerCore` 增持久化——队列+下标整存（`bumpQueue()` 内 `persistSession()`，preferences 库 `suenmusic_player`，键 `session`=JSON `{tracks,index}`）；位置单存（键 `pos`，timeUpdate 5s 节流 + `pause()` 即落 + `loadCurrent` 切歌清零防跨曲残留）。空队列收到 play/next/prev → `restoreSession(intent)`：读回 → 重领流令牌 → play 意图 `pendingSeekMs` 恢复位置、next/prev 挪下标从头播。**时序坑修复**：卡片 router 指令在 `EntryAbility.onCreate` 到达但内核在 NativeRoot 首帧后才 init → `PlayerControlHub` 暂存 `pendingControl`，NativeRoot 在 `init + AppState.bootstrap`（恢复 baseUrl/登录态，续播拉令牌依赖它）完成后 `applyPendingCardControl()` 应用。
2. **2x4 卡片歌词**：`publishTrack` 后 `fetchLyric(track)` 异步拉 `GET /api/lyrics/:id`（`LyricResult.lrc.lyric`，注意是 `{lyric:string}` 包装不是裸串），带 `lyricSeq` 切歌守卫 → `av.updateLyric({assetId, lyric})` → `currentLyric`/`meta.lyric`/`setAVMetadata`/`syncCard` 全链路通，卡片三行歌词窗 + 播控中心滚动歌词就位。
3. **播控中心点击**：第一版理解错——做了 `setLaunchAbility`（API 10+ 确认存在）带 `openPlayer` 参数拉起 APP 内播放页。**用户纠正**：预期是**系统播控中心自己的歌词面板**（点击播放组件翻转展开系统歌词页），不是 APP 内页面。已整链回退（AVSessionManager/EntryAbility/NativeRoot/MediaPlayerCore 四处）。**正解**：歌词面板由 `AVMetadata.lyric`（标准 LRC）驱动——官方 FAQ《如何在播控中心显示歌词》确认只需设置歌词内容，即修复 2 的接线已覆盖。
