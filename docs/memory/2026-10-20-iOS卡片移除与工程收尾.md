## 二、AI 分配下拉溢出（真机截图问题）

安卓真机截图：设置页「AI 分配」两个原生 `<select>` 顶破面板右边界，
行内容也无左右内边距（文字贴边框）。根因：`.select` 用了 `flex:none;
width:180px`，安卓 WebView 里原生 select 不收缩，窄容器直接溢出；
`.row-name` 用 `flex:1 1 auto` 把下拉推到最右。

修法（`components/AiAssignment.vue`）：行加 `padding: 0 var(--sp-4)`、
`justify-content: space-between`；标签 `flex: 0 1 auto` 不伸缩；
下拉 `flex: 0 1 auto + max-width: 60% + min-width: 0` 可收缩。
