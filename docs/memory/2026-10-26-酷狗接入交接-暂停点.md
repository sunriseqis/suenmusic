## 3. 卡点：`vip_token`（唯一阻塞项）

### 实测证据
```
① 扫码登录（酷狗自家二维码）响应 data 只有 5 个字段、仅 token 有值
   日志：酷狗扫码成功：字段 5 个，含 token/vip 的字段：token=有(64)
② 手机号验证码登录 → vip_type=0、vip_token=""（概念版会员在 busi_vip 里，不在这个字段）
③ /v1/user_verify 用扫码 token → "token invalid"(35005)；取流 → 20018
④ 匿名（不带 token）取《富士山下》→ 128kbps、938KB ≈60s
   → 说明"没有真实会员登录态"时酷狗一律只给 60 秒
⑤ 概念版会员状态查询（kugouvip get_union_vip busi_type=concept）
   → busi_vip: is_vip=1, busi_type=concept, product_type=tvip, 到期 2026-10-27 14:53
```

### 第三方客户端为什么能拿完整音频
读 `MakcRe/KuGouMusicApi` 源码（EchoMusic / EchoVIP 均基于它）：
```js
// module/song_url_new.js —— 取流时用的是 cookie 里的 vip_token
const vip_token = params?.vip_token || params?.cookie?.vip_token || '';
tracker_param: { ..., viptoken: vip_token }
```
而 `vip_token` **只有一条登录链会签发**：
```js
// module/login_qq_qr_check.js —— QQ 开放平台扫码
const loginResp = await useAxios({ url: '/v6/login_by_openplat', ... });
const getToken = cryptoAesDecrypt(loginResp.body.data.secu_params, encrypt.key);  // 含 vip_token
cookie.push(`vip_token=${loginResp.body.data?.vip_token || ''}`);
```
QQ 互联 appid（公开在 `util/config.json`）：`qq_appid=205141`、`qq_lite_appid=101706348`。
**酷狗自家扫码（`login_qr_check.js`）在它们的源码里也只 push(token)，同样拿不到 vip_token。**

→ 因此推断：完整音频要求 **酷狗账号绑定 QQ → 用 QQ 开放平台扫码 → 才有 vip_token**。

## 4. 下一步（二选一，需要产品决策）

### A. 接 QQ 开放平台登录（可拿完整 FLAC/320）
工作量约一天，链路：
1. `https://xui.ptlogin2.qq.com/ssl/ptqrshow?...&pt_3rd_aid=<qq_appid>` 出 QQ 二维码
2. 轮询 `ptqrlogin` → 解析 `ptuiCB('0','0',url,...)` → 取 `ptsigx`
3. `check_sig` / `get_openid` / `get_access_token`（含 p_skey）
4. `POST https://gateway.kugou.com/v6/login_by_openplat`（AES/RSA 加密参数，`x-router: login.user.kugou.com`）
5. `secu_params` 解密 → token/userid/vip_type/**vip_token** → 走已有的
   `POST /api/admin/kugou/credentials/import` 落库（**这一步已经做好了**）

风险：QQ 侧滑块/验证码、appid 属酷狗自有（灰色、可能失效）、必须账号已绑 QQ。

### B. 收尾：酷狗只做搜索/元数据
- 现状就是这样，零维护；
- 若要彻底关掉酷狗取流：`resolveKugouSource` 直接返回 `below_threshold`，或在 resolver 链里摘掉该段。

## 7. 踩过的坑（别重复踩）

| 坑 | 现象 | 结论 |
|---|---|---|
| `privilegefilter=1` | 搜不到 VIP 曲（淘金小镇/女儿殿下"无音源"） | 必须 `0` |
| 只取 8 条搜索结果 | 原版被 Live/DJ 挤掉 → 判无匹配 | 取 30 条并按"同名→非版本后缀→时长接近"排序 |
| 用 `privilege===0` 预过滤 | VIP 能播的曲子被全过滤 | 不预判，逐档问 `/v6/priv_url`，拿到非空直链即用 |
| 扫码 appid 写 1014 | token 被 tracker 拒（35005/20018） | 出码 1001、**轮询 3116** |
| 服务端缓存 index.html | web 重新构建后页面还是旧功能 | 已改 mtime 热读 + no-cache |
| 源钉 < 锚点 | 钉了酷狗仍显示哔哩哔哩 | pin 优先级已提到锚点之前；手动锚 B 站时会清钉 |
| 片段当完整音频播 | 播到 60 秒自动跳下一曲 | `estimateCoverage()` 用 Content-Length÷码率估算并跳过 |
