### 3.3 执行方记忆里的**事实错误**（已纠正）

> 它写：「无令牌也能拼，**服务端未强制**」

**错。** `server/src/routes/stream.ts:authorize()` 是三者择一：`?t=` 短期流令牌 / `Authorization: Bearer` / 否则 **401**「缺少播放凭据」。

它没出问题是因为**飞行模式下走的是缓存命中（`fd://`），根本没用到那个 URL**。
危险在于：这条认知传给下一任，会有人拿无令牌 URL 做"简化"，然后在线播放全线 401。

## 5. 交付时的清理与债项

1. **删死码** `common/HarmonyMediaTakeover.ets`（WebView 时代媒体接管层，零引用；与全原生化直接矛盾）。执行方机器上仍有该文件，需同步删除。
2. **技术债**：`AVSessionManager.ets ↔ MediaPlayerCore.ets` 互相 import。真机跑通（双方只在方法体内运行时解引用），但属脆弱设计 → S3 应改为「构造时注入 control handler」断环。
3. **注意**：`pages/Index.ets`（WebView 回退壳）内部有**自己的** `HarmonyAVSessionManager` 副本。改 `common/` 版不影响它；反之改错份会"改了但没生效"。
