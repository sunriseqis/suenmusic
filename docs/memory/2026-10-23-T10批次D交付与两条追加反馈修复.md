## 二、用户追加反馈两条（当轮修复）

### 反馈 1：封面卡尺寸过大（歌手页专辑网格 + 搜索专辑/歌手/歌单三片）
- **根因**：`coverCard` 根节点 `.width('100%')` 在 `Row` 里解析为**整行宽**（两张卡各 100% 行宽 → 溢出超大）。web 是 `minmax(136px,1fr)` 半宽自适应。
- **修法**：SearchPage/CollectionPage 两处 `coverCard` 根节点改 `.layoutWeight(1)`（web 半宽等价物），奇数列占位 `Column().layoutWeight(1)` 原样配合。

### 追加裁定（同日晚）：歌手页专辑网格改 4 列（覆盖 web parity）
- **用户裁定**：专辑封面再小点，一行 4 个（或 8 个），否则专辑区占屏太高、翻太多屏才看到曲目列表。**web neu-grid 移动端 2 列在歌手页专辑区作废**；同规则参照「移除/不加裁定当场进记忆，防机械回补」。
- **落地**：`ALBUM_GRID_COLS=4`，`gridPairs` 按 4 切行 + `padSlots` 不足整行补占位（前张宽度稳定）；行距 s2、行间 s3；`ALBUMS_PER_PAGE=12` 不变（每页 3 行）。搜索页三片网格维持 2 列（web parity 未被裁定推翻）。取 4 不取 8：360vp 屏 8 列每格仅 ~40vp 过小。

### 再裁定（同日更晚）：4 列密度推广为全端网格标准
- **用户裁定**：「这个布局可以，那么其实页面都可以按照这个尺寸布局，看得清也不至于信息密度太低」→ **4 列紧凑网格 = 所有封面卡网格的统一密度标准**（不再是歌手页专辑区单点豁免；web neu-grid 2 列在 hw 网格节整体作废）。
- **落地（搜索页三片）**：SearchPage 新增 `SEARCH_GRID_COLS=4` + `CoverCell` 视图模型类（key/cover/title/sub/circle/onTap）+ `albumCells/artistCells/playlistCells` 投影 + `gridRows` 4 切行 + `padSlots` 占位 + `coverRow` 通用行 builder；三片 ForEach 全部换用（键=行首 cell.key）。单曲分片不动（是列表非网格）。
- **未动**：HomePage 新碟首发（Swiper 一屏 2 张，T5.5 三轮实测定稿的形态，非 CoverCard 网格；如需同密度需用户再点名）、巅峰榜（两列行分组非封面网格）、CollectionPage 头部 148 大封面（详情页头图）。

### 反馈 2：详情页遮挡迷你条，预期迷你条永远置顶
- **web 口径**（MobileShell.vue）：`.mini-dock` 是 `position:fixed + z-index:z-player`，浮在**所有路由页**之上；Tab 栏是 shell 网格行同样常驻；唯一盖住它的是全屏 FullPlayer。即：**迷你条/Tab 栏是壳件，页面（含详情页）只允许占内容区**。
- **修法**（NativeRoot.build 重排）：
  - 内容 Tabs + scrim + Servers/Cache/Collection 浮层全部收进内层 `Stack().layoutWeight(1)`；迷你条 + Tab 栏保持流内置底 → 浮层天然只占 dock 以上内容区，**dock 永远置顶且可点**
  - 播放页仍为全屏 Stack 顶层（唯一允许盖 dock 的浮层，web FullPlayer 同口径）；其 scrim 拆为全屏独立一份
  - 连带修正 ①`onBackPress` 层级顺序：player > collection > servers > cache（原顺序 collection 先于 player，播放页盖着集合时返回键会误弹集合内层）②切 Tab 时关闭所有详情浮层（web 点 tabbar=路由导航语义，否则浮层下切 tab 像死按钮）
  - **避让区防双倍**：CachePage/CollectionPage 原自带 `topAvoid/bottomAvoid` padding（此前是全屏 Stack 兄弟需自理），收进壳层 padding 内后摘除各自 avoid（CachePage 删 @StorageProp+avoidVp+root padding；CollectionPage root padding 改 `top:s2/bottom:s4`，删 avoid 成员）。PlayerPage/LoginPage 仍全屏自理，不动。
- ServerListPage 本无 avoid 处理，进壳层后反而获得顶部避让（顺带修正）。
