## 二、本轮**补上**的（此前确实没接）

1. **`AudioEngine.setQueue` 从不调用 `LocalStreamProxy.configure(base:token:)`** —— 代理 `upstreamBase` 为空 →
   播放全程直连 → AVPlayer 带 Range 拉流 → 被限速 40KB/s → fMP4 起不来 → 「点了不出声」。
   （这就是 §九-10 那条教训在我们这儿的直接后果。）
2. **`LSApplicationQueriesSchemes` 没登记 `altstore` / `sidestore`**（§九-6）→ `canOpenURL` 恒 false，
   更新会被静默降级成 Safari。已补白名单 + 投递阶梯（altstore → sidestore → Safari，对齐 §5.3）。
3. 服务端 `application/octet-stream` → 按首块嗅探成 `audio/mp4`，并**在 reply.send 之前**覆盖（HEAD 探针也生效）。
