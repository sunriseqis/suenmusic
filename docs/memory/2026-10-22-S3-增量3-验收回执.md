## 【测试中发现并修复】（2 个，均已重新构建装机验证）

1. **ServerListPage 顶栏缺「新增」按钮**：`addForm` 的 `adding` 没有任何置 true 的入口，验收 #2 直接被堵死。修复：顶栏改 `[返回][Blank][标题][Blank][新增]`，按钮 toggle `adding`。
2. **`APIClient.probe()` 裸发请求未显式 Content-Type**：鸿蒙 http 栈对空 body 也会注入 `Content-Type: application/json`，Fastify 遇「json 头 + 空 body」直接 400 → 探测永远失败。修复：probe 显式 `header: {'Content-Type': 'text/plain'}`（与 `buildHeaders` 的空 body 策略对齐，`APIClient.ets:222-240`）。

## 【补充】编辑功能 + 压测（2026-10-22 下午，Lead 反馈驱动）

### 编辑功能（Lead 反馈缺编辑按钮，当轮实现并验证）

- 每行新增「编辑」按钮；底部表单改**双模式**（`editingIndex >= 0` = 编辑模式，预填名称/地址，标题「编辑服务器」/按钮「保存」；`-1` = 新增模式，原逻辑不变）

- 校验与新增一致：http(s) 前缀、去重（排除自身）、空名称保留原名

### 编辑模式一个真 bug（Lead 实测发现，已修复）

**只改名称时列表不刷新**，退出页面重进或改地址后才显示——根因：`ForEach` 键生成器只用了 `s.url`，键不变则 ArkUI 不重绘该条目。修复：键改 `s.url + '|' + s.name`（`ServerListPage.ets` ForEach 第三参数）。
