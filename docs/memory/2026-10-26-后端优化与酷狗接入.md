## 二、直链通道（服务端拿链接下发设备）

历史决策 `2026-10-20-终止直连回归服务端.md` 终止的是「客户端自己解析」，不是「服务端下发直链」——四条失败原因对新形态全部不成立（除反爬需客户端 403 回退）。

- 服务端：resolve 新增 `directUrl`/`directHeaders`（**只 UA+Referer，绝不含 Cookie**）/`directExpiresInSec`；`SUENMUSIC_DIRECT_LINK=off` 一键回退；代理永不删
- hw：`createMediaSourceWithUrl(url, headers)` + `setMediaSource`；解析超时 800ms；**失败自动回退代理**（按曲目 id 防循环）
- **模拟器实测**：`直链装载 exp=1799998ms`、AVSession 时间轴推进、服务端 /api/stream 零请求

## 三、酷狗接入（三份调研 + 用户拍板）

- **不做**：签到换会员（kg-checkin 实为伪造广告播放上报，刷量）、汽水（需逆向字节签名）、酷狗直链逆向对抗（EchoMusic 证明业界通行做法是"逆向库内联+真人过验证"，无头服务吃亏）
- **做**：元数据兜底（匿名实测 status=1）+ **VIP 取流**（用户自持概念版会员）

**关键技术点（全部实测）**：
1. 概念版签名盐 `LnT6xpN3khm36zse0QzvmgTZ3waWdRSA` ≠ 标准版（`OIlwieks…`）；appid 3116/clientver 11440
2. **取流必须走 gateway + x-router**：`http://gateway.kugou.com/v6/priv_url?…` + header `x-router: tracker.kugou.com`；/v5/url 已废（illegal pid）；media.store 不可直连（需 x-router）
3. **body 参与签名**：MD5(盐+排序参数串+**JSON body**+盐)——漏掉 body 就 invalid sign
4. 权益是逐档的：`relate_goods` L2=128/L4=320/L5=FLAC/L6=Hi-Res；viper 系列需超级 VIP
5. 直链在 `data[0].info.tracker_url[]`；`_msg: "Allow: …"` 是提示不是错误
6. 扫码登录：拿 key/轮询用 web 盐+appid 1014；**轮询也要全套公共参数+kg-* 四头+注册 dfid**（缺一 20010）；用户用概念版 App 扫

**Web 面板**：设置→音源授权三行（B 站/网易云/酷狗（概念版）），扫码 Sheet 与 B 站/网易云同构；admin 接口 `/api/admin/kugou/{login/qr,login/poll,credentials}`

**Spike 实测**（userid=2302235937）：FLAC 取流 3/3，`突然好想你` 871kbps 真 flac，CDN HEAD 200；「处处吻」酷狗无版权→印证多源兜底必要性

## 四、网易云「扫码成功却显示未授权」

根因：`loginStatus` 响应体**只有 data 键**，`verifyAccount` 要求 `code===200` 判死 → 扫码时 cookie 落库但账号被删 → 三端永远未授权（hw/ios 之前看到的「cookie 失效」就是它）。
修复：判定改 account.id+profile.nickname 存在即有效 + `getNeteaseStatus` 触发**异步回填**。实测 account 恢复（八十九啊）。
