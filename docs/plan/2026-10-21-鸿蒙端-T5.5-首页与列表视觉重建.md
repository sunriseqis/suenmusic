> **状态：起草完毕，T6 完成后实施。**

## 二、鸿蒙端逐区块实现

### 2.1 首页 `HomePage.ets`（重建）

| web 区块 | 鸿蒙实现 | 要点 |
|---|---|---|
| 欢迎语 | 现有（保留），字号提级 | — |
| **新碟海报横滑** | `Swiper`（`SwiperDisplayMode.Auto`，禁用圆点指示器则用 `Indicator` 定制） | 每页 1-2 张大卡（卡宽 ~60-70% 屏宽，露出下一张边缘 = scroll-snap 的视觉暗示）；卡 = `Image(封面)` + 日期角标（`Stack` 叠加，右上）+ 底部名称/歌手（渐变 scrim 或独立行）+ **凸面板描边**（`Tokens.panel` 底 + `Tokens.line` 1px 描边） |
| **新歌列表** | 现有 `TrackItem`（保留），但行首加**序号/封面权重**对齐 web | — |
| **巅峰榜两列** | `Grid`（`columnsTemplate: '1fr 1fr'`）+ 榜单卡：封面 + badge「榜」（`Tokens.accent` 圆角小块）+ 榜名 + `updateFrequency` 副文案 | 卡片点击 → 榜单页（若 T3 前无榜单详情页，先占位 Toast「即将上线」并入 T8） |
| **播放全部**（榜单卡内/下） | `Tokens.accent` 宽按钮，与 web 同位置 | — |
| 离线横幅/骨架屏 | 现有（保留） | 骨架屏条目形态改为"海报占位 + 列表占位"两段 |

### 2.2 收藏 / 专属列表（对齐）

- 行视觉权重：封面 44→`Dim.s5*2`（48）+ 名称/歌手双行 + 红心动作区（保留右滑手势，T2 产物）
- 收藏页：序号染琥珀逻辑保留（web 同款），但 web 移动端行内红心隐藏——**右滑是唯一收藏入口**（现有实现已对齐，确认不回退）

### 2.3 哑光质感（全局）

- 海报卡/榜单卡/账号卡 = 凸面板：`backgroundColor(Tokens.panel)` + `border(1px, Tokens.line)` + 上缘内高光（线性渐变 1px，可后置）
- 列表行 = 平铺 + 发丝线分隔（`List .divider`）
- **禁止 ArkUI shadow API 硬仿**（哑光的厚度=色差+线，硬仿会假）

## 三、设置项取舍（用户口径：以 web 移动版设置页为准）

T8 设置页实施前，对照 `web/src/views/Settings.vue` 的**移动断点**：
- web 移动端**不出现**的管理区块（AI 模型/账号管理/数据维护/更新通道）→ 鸿蒙设置页**不出现**
- web 移动端有的设置项 → 鸿蒙对应出现
- T8 单子的分区表按此修订后再执行
