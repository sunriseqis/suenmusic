## 二、每项任务的「不可让渡」部分（其余交给智能体的工具与判断）

单子里分两类内容，执行时请按此区分：

| 类别 | 含义 | 例子 |
|---|---|---|
| **契约（必须遵守）** | 服务端字段/路径/语义、状态机时序、验收判定 | `hasMore` 是分片级"还有下一页"不是总数；`shortfall` 不是错误；`audioRendererInfo` 只在 `initialized` 设；切服后 `positionMs` 差 < 3 秒 |
| **实现建议（可优化）** | 具体写法、组件拆分、用哪个 API、动效曲线 | `LazyForEach` 怎么实现 `IDataSource`、动效用哪个 `curve`、图标用 `sys.symbol` 还是 svg |

**智能体可用官方文档 MCP 校验 API 签名**；若单子里的写法与实际 API 不符，**以官方文档为准**，
但要在回执里注明「单子写法 → 实际做法 → 原因」，我会更新单子。

## 三、全局不可破的六条（跨所有任务）

1. **播放状态机由 `stateChange` 唯一驱动**：`url` 只在 `idle` 赋、`audioRendererInfo` 只在 `initialized` 设、`prepare` 在 `initialized`、`play` 在 `prepared`
2. **单首失败不是致命错误**：`failStreak < 3` → 600ms 后跳下一首；`≥ 3` 停下给人话；`fail()` 有单次闸门
3. **AVSession 推送有闸门**：在飞即丢 + 900ms 间隔 + 按 `assetId` 去重（含 `currentMetadata !== null`）
4. **UI 不持有真相**：队列/播放态只读快照（`K_QUEUE_VERSION` / `K_INDEX`），增删改一律走内核方法
5. **缓存只落 `filesDir`**，删除时跳过正在播放的文件
6. **颜色只走 `Tokens.*`**（唯一例外错误色 `#E5484D`）；进入 T5 后尺寸也只走 `Dim.*`
