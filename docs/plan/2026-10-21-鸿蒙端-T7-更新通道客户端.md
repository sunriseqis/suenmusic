## 一、服务端契约（Lead 已实现并通过 tsc，2026-10-21）

`updatePlatform` 现在接受 `android | ios | harmony`；产物命名规则
`SuenMusic-v<版本>-release.hap`；大小上限 150 MB；MIME `application/octet-stream`。

### 1.1 检查更新

```
GET /api/update/check?platform=harmony&version_name=1.6.0&version_code=20123&force=1
Authorization: Bearer <accessToken>
```

返回（与 android/ios 同构）：

```jsonc
{
  "available": true,
  "current": { "versionName": "1.6.0", "versionCode": 20123 },
  "latest": {
    "fileName": "SuenMusic-v1.6.1-release.hap",
    "path": "...",              // 上游路径，客户端不要用
    "versionName": "1.6.1",
    "versionCode": 20124,
    "size": 41234567,           // 字节
    "sha256": "..." | null
  },
  "downloadPath": "/api/update/download",
  "downloadToken": "<短期令牌>"
}
```

- `version_name` 必须是 `1.2.3` 形式（服务端强校验），`version_code` 是整数
- `force=1` 跳过服务端 5 分钟缓存 —— **用户手点「检查更新」时必须带**
- 失败码：`update_not_configured`（服务端未配置更新目录）/ `update_upstream_failed`（上游不可用）/ `invalid_platform`

### 1.2 下载

```
GET /api/update/download?platform=harmony&token=<downloadToken>
```
- `token` 是 check 签发的短期令牌，**不需要** Authorization 头（浏览器/系统下载器发不出头）
- 响应 `Content-Type: application/octet-stream`，文件名 `SuenMusic-v<版本>-release.hap`

## 二、客户端的正确做法（**别在应用内下载**）

鸿蒙普通应用**没有安装其它应用的权限**。所以应用内下载 HAP 只会得到一个装不上的文件。
用户已有移动端侧签工具，它会**拦截 `.hap` 下载并自动完成签名安装**。

因此客户端只做三件事：

1. **检查更新** → 拿到 `available` / `latest.versionName` / `downloadToken`
2. **把下载地址交给系统**（浏览器或系统下载器），由侧签工具接管后续
3. **展示状态**（当前版本、最新版本、大小、检查中/已是最新/检查失败）

### 2.1 打开系统下载的具体方式

```
拼 URL：<base>/api/update/download?platform=harmony&token=<downloadToken>
然后用 UIAbilityContext.startAbility 打开系统浏览器（want.action = 'ohos.want.action.viewData'，uri = 上面那个 URL）
```

- 不要用 `request.agent` 在应用内下载（装了也打不开，且要处理公共目录权限）
- 不要尝试 `bundleManager` 安装（无权限，必然失败）
- 打开前给一句提示：「即将在浏览器下载并交给侧签工具安装」

### 2.2 版本号来源

客户端当前版本不要硬编码：用 `bundleManager.getBundleInfoForSelfSync()` 取
`versionName` / `versionCode`，传给 check。若取不到，退化到常量并由 `AppState` 记录。

## 三、触发时机（已定：轻量轮询，不做长连接）

| 时机 | 说明 |
|---|---|
| 登录成功后 | 调一次 `check(force=false)` |
| 应用回前台（`onForeground`） | 再调一次（间隔 < 5 分钟则跳过，避免频繁） |
| 应用在前台期间 | 每 10 分钟一次；**不建长连接**（鸿蒙后台会冻结 WebSocket/SSE，收益为零） |
| 用户手点「检查更新」 | `check(force=true)`，强制去上游核对 |

有更新时展示**顶部横幅**（不是模态弹窗，避免打断播放）：「新版本 x.y.z（xx MB）」+「查看」；
点「查看」进设置页更新区块，再点「下载并安装」。

## 五、验收（5 条）

| # | 操作 | 判定 |
|---|---|---|
| 1 | 打开设置页 | 显示当前版本（与 `bundleManager` 一致） |
| 2 | 点「检查更新」（更新目录里没有新 HAP） | 「已是最新版本」；无报错弹窗 |
| 3 | 把 `SuenMusic-v9.9.9-release.hap` 放进更新目录后再点 | 「发现新版本 9.9.9（xx MB）」+「下载并安装」按钮 |
| 4 | 点「下载并安装」 | 跳到浏览器开始下载 `.hap`；侧签工具接管安装；**应用不崩溃、不卡死** |
| 5 | 关掉更新目录配置（或断网）后点 | 人话提示（`update_not_configured` / 网络失败），**不重试轰炸** |

### 回归门禁

- 后台播放与锁屏仍正常（检查更新不得打断播放）
- 无新增 WARN、`arkts_check` 0 ERROR
