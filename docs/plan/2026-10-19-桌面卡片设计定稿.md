# 桌面卡片（小组件）设计定稿 · 2026-10-19

> 方向：**仪表盘**。封面不再当整块海报，元素按发丝线网格分区。


## 规格

### 2×2 · 160 × 160

> 歌名允许两行（12.5px，2 行截断）。单行时只能显示 4~5 个字，长标题不可用；
> 封面从 64 收到 52 给文字让宽。

```
┌────────────────────┐
│ ┌────┐  夜航        │   封面 52 方块 + 标题（2 行）/ 歌手
│ └────┘  林间        │   收藏固定在右上角
│              1:34   │   时间码在进度线右上
│ ▬▬▬●░░░░░░░░░░░░  │   2px 进度线，兼作分区线
├────────────────────┤
│      ⏮   ▶   ⏭      │   三键居中：22 / 30 / 22，间距 10
└────────────────────┘
```

### 2×4 · 340 × 160

```
┌────────┬──────────────────┬────┐
│        │ 夜航            ♥ │    │
│  封面   │ 林间 · 专辑 夜航   │ ⏮  │
│  84    │ 海面没有回声        │ ▶  │
│        │ ▍我们就一直向前     │ ⏭  │
│        │ 直到天亮之前        │    │
│        │ 1:34 ▬▬●░░ 4:08   │    │
└────────┴──────────────────┴────┘
  112px          1fr            56px
```

- 三格：封面 / 信息 / 运输轨，全部 1px 发丝线分隔
- 信息格：歌名 14 / 歌手 10 / 三行歌词 / 时间 + 进度
- 右轨：三键纵向居中（22 / 34 / 22，间距 12），**不放收藏**

### 空态

```
封面位 → 音符占位
标题   → 暂无歌曲播放
副标题 → 不显示
时间   → --:--
歌词   → 不显示
收藏   → 2×2 不显示；2×4 保留（灰色）
控制   → 三键灰掉，不响应点击
```

## 规则

| 项 | 决定 | 理由 |
|---|---|---|
| 收藏位置 | **只在 2×4** 的信息格右上角 | 2×2 加收藏会显得拥挤，且挤掉标题宽度；它是状态，不是运输键 |
| 运输键 | 固定三键，左右对称 | 上一首 / 播放 / 下一首 |
| 歌词 | 2×4 正面直接显示三行 | 宽卡空间足够，翻面只会多一次点击 |
| 翻转 | **取消** | 删除 `flipAngle` / `showBack` / `rotate` |
| 时间码 | 2×2 放进度线右上；2×4 在进度行左端 | 等宽字体 |
| 视觉 | 无外阴影、琥珀只给播放键/进度/当前歌词 | 与 App 哑光硬件一致 |
| 点击 | 非按钮区 → 打开应用；按钮 → `postCardAction` | 沿用 alive 分流 |

## 数据

现有字段够用，不需要新增：

```
suen_title / suen_artist / suen_cover / suen_playing
suen_favorite / suen_lyric / suen_lyric_active
suen_alive / suen_dimension / formId
```

`dimension === '3'` → 2×4；其余 → 2×2。

## 实现要点

- **鸿蒙**：改写 `hw/entry/src/main/ets/forms/SuenFormCard.ets`
  - 删除翻转相关状态与动画
  - 2×4 信息格加三行歌词（`suen_lyric` 按 `\n` 拆分，`suen_lyric_active` 高亮）
  - 收藏移到信息格右上；右轨只留三键
  - 2×2 运输带改为三键居中，时间码放进度线右上
- **Android**：RemoteViews 从零实现，结构照搬；进度条是静态快照，
  只在播放状态/曲目变化时推，不做平滑动画
