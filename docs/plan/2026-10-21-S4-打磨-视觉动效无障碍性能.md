# 2026-10-21 S4：打磨（视觉 / 动效 / 无障碍 / 性能）

> 前置：S3 四个增量全部通过。
> **本阶段只改表现层**：不改数据流、不改状态机、不改接口。
> 目标是让"能用的毛坯"变成"愿意每天用的客户端"。

## 一、尺寸与间距收进常量（先做这个，否则后面到处改）

新增 `common/Dimension.ets`：

```ts
export class Dim {
  static readonly s1 = 4;  static readonly s2 = 8;  static readonly s3 = 12;
  static readonly s4 = 16; static readonly s5 = 24; static readonly s6 = 32;
  static readonly radiusSm = 6; static readonly radiusMd = 12; static readonly radiusLg = 16;
  static readonly fsCaption = 11; static readonly fsBody = 13; static readonly fsTitle = 15;
  static readonly fsHeadline = 18; static readonly fsDisplay = 20;
  static readonly touchMin = 44;   // 可点区域下限（vp）
  static readonly rowHeight = 56;
}
```

要求：所有页面的 `padding/margin/borderRadius/fontSize/height` **不得出现裸数字**（0 除外）。
验收时会 grep 页面里 `\.padding\([0-9]` 这类模式，命中即打回。

## 二、动效（统一 200ms / `Curve.EaseOut`）

| 交互 | 效果 |
|---|---|
| Tab 切换 | 内容淡入 + 轻微上移 8vp |
| 播放页展开/收起 | `transition` 上滑 + 背景不透明度 0→1 |
| 三视图切换（封面/歌词/队列） | 交叉淡入（100ms） |
| 按钮按压 | `scale(0.96)` + 回弹 |
| 列表项点击 | 高亮反馈（`Tokens.panel`） |
| 歌词滚动 | 已用 `scrollToIndex(smooth)`，保持 |

禁止：超过 300ms 的动效、`spring` 曲线乱用（只允许 `EaseOut`/`Friction`）。

## 三、无障碍

- 所有**图标按钮**补 `.accessibilityText('播放'/'暂停'/'上一首'/'下一首'/'删除'/'收起')`
- 可点区域 ≥ `Dim.touchMin`（44vp）：队列删除键当前 28vp 高 → 扩大热区（视觉可仍小）
- 对比度：`Tokens.text2 (#8A8D93)` on `bg (#0E0F11)` ≈ 5.6:1（达标）；**检查** `Tokens.text2` 用在 `panel (#17181B)` 上的次级文案是否仍 ≥ 4.5:1
- 系统字号放大到 1.3× 时，播放页标题不得被裁切（`maxLines(2)` + 省略号）

## 四、性能

| 项 | 目标 | 手段 |
|---|---|---|
| 首页/队列滚动 | 60fps（DevEco Profiler 采样 10s，无 >16ms 长帧） | 长列表改 `LazyForEach` + 自定义 `IDataSource`（首页新歌、搜索结果、收藏页三处） |
| 冷启动 | 模拟器参考 < 1.5s 到首屏 | 首页快照（增量 4 已做）先渲染；`AVSession.init()` 延后到首帧后 |
| 内存 | 滚动 100 行后 RSS 无持续上涨 | 封面图 `ImageFit.Cover` + 不缓存原图；列表项避免闭包持有大对象 |
| 歌词 | 800 行不卡 | 已用 `LazyForEach`? 否 → 改 `LazyForEach` |

## 五、空态统一

新增 `pages/EmptyState.ets`（图标 + 标题 + 副文案 + 可选按钮），替换现有零散空态：

| 场景 | 标题 / 副文案 |
|---|---|
| 搜索无结果 | 没找到相关歌曲 / 换个关键词试试 |
| 收藏为空 | 还没有收藏 / 在播放页点心形就能收藏 |
| 每日 shortfall | 曲库还太少 / 先多听几首再来看 |
| 歌词无 | 这首歌暂无歌词 / — |
| 队列空 | 队列是空的 / 去首页挑一首 |

## 六、骨架屏

首页首次加载（无快照）用骨架块（3 行灰条 + 脉动）替代 `LoadingProgress`；收藏/搜索首次加载同样。

## 七、图标

- 播放控制、删除、收起等：优先用系统 Symbol（`$r('sys.symbol.play_fill')` 之类）或现有 `card_*.svg`
- 禁止 emoji 当图标
