# 小组件扩展未建 target，测试包里没有卡片（2026-10-19）

> **状态：已解决。** 扩展 target、Embed 阶段、两侧 entitlements 均已写入
> `project.pbxproj`，模拟器构建产物含 `App.app/PlugIns/SuenMusicWidget.appex`。
> 落地过程与验证口径见 `docs/memory/2026-10-19-小组件扩展target补齐.md`，
> 下文保留为问题记录。

## 现象

本版更新了桌面卡片小组件，但装到模拟器/真机的测试应用里，主屏"添加小组件"
列表里找不到 SuenMusic，也不会有卡片。

## 根因

**`ios/App/SuenMusicWidget/` 只有源码，Xcode 工程里从来没有建过扩展 target。**

实测：

- `project.pbxproj` 里只有一个 target，`productType` 仅
  `com.apple.product-type.application`（App 本体）；
- 构建产物 `App.app/` 内没有 `PlugIns/` 目录；
- `SuenMusicWidget.swift`、`SuenMusicWidget-Info.plist`（含
  `NSExtensionPointIdentifier = com.apple.widgetkit-extension`）、
  `SuenMusicWidget.entitlements` 都在，但没有任何构建阶段引用它们；
- 已被加进 App target 的只有 `SharedNowPlaying.swift` 和
  `PlaybackIntents.swift` 两个**共享源码**（所以 App 侧的就地播放命令能用，
  但卡片本体不存在）。

`cap sync` 只同步 web 产物，不会补 target；这是工程搭建时漏掉的一步。

## 需要补的东西

1. **新建 Widget Extension target**（Xcode：File → New → Target →
   Widget Extension，勾选 "Include Configuration Intent" 可不选）：
   - Product name：`SuenMusicWidget`
   - Bundle ID：`com.suenmusic.app.widget`（必须是 App ID 的子级）
   - 把现有 4 个文件替换进去：`SuenMusicWidget.swift`、`SuenMusicWidget-Info.plist`
     按模板生成的 Info.plist 替换、`SuenMusicWidget.entitlements`、
     以及共享的 `SharedNowPlaying.swift`
2. **两个 target 都要接 App Groups**：`group.com.suenmusic.app`
   - App target：`CODE_SIGN_ENTITLEMENTS` → `App/App.entitlements`
     （⚠️ 当前工程完全没接，见下）
   - Widget target：`CODE_SIGN_ENTITLEMENTS` → `SuenMusicWidget/SuenMusicWidget.entitlements`
3. **Embed**：App target 的 "Frameworks, Libraries, and Embedded Content"
   里把 `SuenMusicWidget.appex` 设为 Embed & Sign（对应 pbxproj 的
   Copy Files 阶段 `dstSubfolderSpec = 13`）。
4. 版本号：widget 的 `MARKETING_VERSION` / `CURRENT_PROJECT_VERSION`
   需与 App 一致（脚本用命令行覆盖，扩展 target 也要覆盖或继承）。

## 顺带：App.entitlements 也没接线

整个 pbxproj 没有任何 `CODE_SIGN_ENTITLEMENTS`。`App/App.entitlements`
（`group.com.suenmusic.app`）是"孤儿文件"，所以即使卡片 target 建好，
App 与 Widget 之间的 App Groups 共享数据仍不成立——
`SharedNowPlaying` 那条链会拿不到数据。建 target 时要一并接上。

## 验收

- `xcodebuild` 产物里出现 `App.app/PlugIns/SuenMusicWidget.appex`；
- 模拟器主屏长按 → 添加小组件 → 能搜到 SuenMusic；
- 卡片能显示当前播放（说明 App Groups 通了）。
