# 后端一体化与账号体系（2026-10-19 定稿）

> 从"服务端 + Web 客户端"改成"Web 就是后端的一部分"。移动端是唯一真正的客户端。

## 一、边界

```
Web      同源，由服务端自己发出；不配置地址、没有多服务端
         登录 = HttpOnly cookie 会话；不续期、不存令牌
移动端   真正的客户端：Bearer access + refresh；可直连上游
服务端   唯一实例；静态资源与 /api 同端口
仓库     suenmusic 单仓；suenmusic-server / suenmusic-mobile 只读
```

服务端源码已迁入本仓 `server/`，静态目录指向 `../web/dist`。

## 二、账号与权限

```
第一个账号   自动成为管理员（/login 首次显示「创建管理员」）
管理员       音源扫码授权、AI 模型增删改、账号管理、注册开关、
             数据库备份与健康检查
成员         播放、搜索、收藏、历史、画像、调优、使用已配置的 AI
数据隔离     完全隔离；管理员也看不到成员的内容
注册         默认关闭；管理员可开
```

## 三、Cookie 与授权

```
B 站 / 网易云 cookie   全局一份（家庭实例），管理员扫码，成员共用
缓存                   跟随唯一出网身份，全局
移动端                 可获取该 cookie 用于直连（接受设备侧凭据风险）
```

将来若出现多身份需求，再引入"授权对象 + 分配关系"，缓存键跟着授权 ID 走。

## 四、安全基线

```
反向代理   信任 X-Forwarded-Proto / X-Forwarded-For
Cookie     HttpOnly + SameSite=Lax + HTTPS 时 Secure
CSRF       写请求必须带 X-Requested-With: suenmusic
登录       按 IP + 账号限流（复用服务端现有节流）
```
