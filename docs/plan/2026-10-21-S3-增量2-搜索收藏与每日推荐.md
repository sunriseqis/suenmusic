## 一、服务端契约（已核对源码，**照这个写，不要猜**）

### 1.1 搜索

```
GET /api/search?q=<关键词>&type=all|song|album|artist&page=1&limit=30
```
- `page`：1–100；`limit`：1–50（默认 30）
- 返回 `SearchResult`：
  ```ts
  { query, type, page, limit,
    songs: Track[], albums: Album[], artists: Artist[], playlists: Playlist[], mvs: Object[],
    hasMore: { song: boolean, album: boolean, artist: boolean, playlist: boolean },
    degraded: object | null }
  ```
- ⚠️ `hasMore` 是**分片级"还有下一页"**，**不是总数**。搜歌手时 `songs` 恒空属正常，
  不能因为 `songs.length === 0` 就判定"没结果"——要看你当前切的是哪个分片。

### 1.2 收藏

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/favorites?limit=&cursor=` | 返回 `{ items: [{trackId, createdAt, track?}], total, nextCursor? }`；`nextCursor` 为空即到底 |
| POST | `/api/favorites` | body `{ trackId, track? }`（带 `track` 可顺带写快照，省后续补全） |
| DELETE | `/api/favorites/:trackId` | 返回 `{ ok: true }` |
| POST | `/api/favorites/check` | body `{ ids: string[] }`（≤500）→ `{ favorites: { [id]: boolean } }` |

> ⚠️ **T2 实测踩坑（2026-10-21 回执）**：`nextCursor` 到底时服务端返回的是 **`null`**
> （`server/src/routes/favorites.ts` GET 的三元 else 分支），不是空串也不是缺字段。
> 客户端只防 `undefined` 会 `null.length` 崩（收藏页整页「Cannot read property length of null」）。
> 必须归一：`nextCursor = page.nextCursor ?? ''` 后再判空。

### 1.3 每日推荐

```
GET /api/recommend/daily
```
- 返回 `{ status?: 'shortfall' | ..., date: string, greeting?: string, welcomePhrase?: string, tracks: Track[] }`
- **只读**：歌单由服务端每天 00:30 定时产出。**没有** `?force=1`（"换一批"已按用户要求关闭）
- `status === 'shortfall'` 或 `tracks` 为空 = 曲库不足。**这不是错误**，界面要说人话
  （「曲库还太少，先多听几首再来看」），不要显示"加载失败"、不要重试轰炸

## 一点五、UI 布局规范（**缺了这节导致第一版页面没对齐 —— 先读这节再动手**）

### 底部导航栏（`NativeRoot` 的 `Tabs`，T2 起扩为 5 个）

```
┌──────────────────────────────────┐
│  <页面内容>                       │
│  …                               │
│  [迷你播放条（有曲目时）]          │
├──────────────────────────────────┤
│ 首页   搜索   收藏   每日   我的   │  ← barPosition.End，5 个 Tab
└──────────────────────────────────┘
```

- Tab 顺序与名称**固定**：首页 / 搜索 / 收藏 / 每日 / 我的
- 每个按钮 = 图标（系统 Symbol 或自绘 SVG，见下）+ 文字（`Dim.fsCaption`），
  选中态 `Tokens.accent`、未选中 `Tokens.text2`
- 图标参考：首页 `house`、搜索 `magnifier`、收藏 `heart`、每日 `calendar`、我的 `person`
  （HarmonyOS Symbol 名以官方图标库为准；拿不到就用 `card_*.svg` 同风格自绘）

### 各页面骨架（信息层级从上到下）

| 页面 | 结构 |
|---|---|
| **搜索** | 顶部固定搜索框（圆角 `Dim.radiusMd`，放大镜图标）→ 分片切换（单曲/专辑/歌手，胶囊样式同播放页三视图）→ 结果列表（复用 `TrackItem`）→ 底部「加载更多」 |
| **收藏** | 标题行（「我的收藏」+ 总数）→ 列表（TrackItem，右侧红心实心可取消）→ 空态 |
| **每日** | 顶部欢迎语（`welcomePhrase`，大字）→「播放全部」按钮（`Tokens.accent` 宽按钮）→ 列表 |
| **我的**（T8 前的过渡版） | 账号卡片 → 分组列表（服务器/缓存/关于占位）→ 退出 |

### 关键交互一致性（与现有页面保持同一套手感）

- 列表行高 `Dim.rowHeight`（56vp），点击态背景 `Tokens.panel`
- 点击歌曲 = **替换整个播放队列**并从该条起播（`setQueue`，语义与首页一致）
- 页面切换不重建播放（Tab 只是内容容器，播放态在内核）
- 空态一律居中 + 一句话 + 可选按钮，用 T5 之后的 `EmptyState`；T5 之前先内联居中文案

## 三、四条约束（违反即打回）

1. **播放只有一个入口**：任何页面点歌都走 `MediaPlayerCore.shared().setQueue(tracks, index, token)`；
   令牌获取失败时**降级为空令牌继续**（缓存曲走 `fd://` 不需要令牌），与 `HomePage.playAt()` 完全一致。
   禁止在页面里自己拼 stream URL。
2. **收藏状态不要塞进播放内核**：`K_*` 通道只服务播放态。收藏与否由页面自己 `checkFavorites()` 拉，
   或用 `track.id` 命中本地集合。不要把收藏集合写进 `AppStorage` 让播放内核感知。
3. **搜索的 `hasMore` 按分片判断**：切到"歌手"分片时用 `hasMore.artist`，不要用 `songs.length`。
4. **`shortfall` 不是错误**：每日推荐为空/不足时给引导性文案，**不要**重试循环、不要 toast 报错。

## 四、验收 8 条（缺一不算过）

| # | 操作 | 判定 |
|---|---|---|
| 1 | 搜索「周深」 | 单曲分片有结果；切「歌手」分片能看到歌手条目（不是空列表） |
| 2 | 搜索结果下滑翻页 | 追加下一页，不重复、不跳条；到底后不再请求 |
| 3 | 最近搜索 | 搜完返回/重进页面，关键词仍在列表里；可单条删除或清空 |
| 4 | 收藏页首屏 | 按 `createdAt` 倒序，显示总数；滚到底自动加载下一页或无更多 |
| 5 | 取消收藏 | 条目立即消失、总数 -1；杀掉进程重进仍是取消状态（服务端已落库） |
| 6 | 收藏页点歌 | 立即出声，底部播放条更新，队列换成收藏列表且当前项正确 |
| 7 | 播放全部（每日推荐） | 队列 = 当日歌单，从第 1 首起播 |
| 8 | 每日推荐为 `shortfall` | 显示引导文案（非"加载失败"），**无**自动重试 |

### 回归门禁（每加一页都要过）

- 进出各 Tab 后，**后台播放与锁屏仍正常**
- 无 `SetAVPlaybackState ... timeout` 刷屏
- 同一首不出现重复 `updateMetadata`（封面只下一次）
- 新页面颜色全走 `Tokens.*`（错误色 `#E5484D` 唯一例外）
- `npm run hw:check`（若有 Node 环境）或 IDE 内 `arkts_check` 通过

## 五、编译注意（本增量高风险点）

| 点 | 说明 |
|---|---|
| `@Builder` 命名 | 不得撞 ArkUI 内置属性（已踩 `dragPreview`/`position`/`tabIndex`）。公共行组件建议用 `TrackItem` 而非 `Row`/`Item` |
| ArkTS 禁 `any` | 搜索返回的 `mvs`/`degraded` 若不展示，声明成 `Object[]`/`Object \| null` 即可，别用 `any` |
| `Tabs` 扩到 5 个 | `TabContent` 里不能再嵌 `Tabs`；`currentTab` 成员名保持（不要改回 `tabIndex`） |
| `preferences` 存最近搜索 | 用 `@kit.ArkData`，读写都要 `await flush()`；上限 10 条，去重按 `q` |
| 列表分页防重入 | 用 `loadingMore` 布尔闸门；`onReachEnd` 触发时若已在加载直接返回 |
