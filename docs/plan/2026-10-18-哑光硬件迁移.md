# 哑光硬件 UI 迁移 · 计划与进度

> 2026-10-18。设计方向已拍板，第一阶段（token + 基础组件 + 播放页 + 列表）已落地并真机验证。

## 一、已确认的设计决策

| 决策 | 结论 | 理由 |
|---|---|---|
| 视觉方向 | **哑光硬件（Matte Hardware）** | 同一族但比 neumorphism 现代一个世代：靠材质、比例、机械反馈，不靠拟真纹理 |
| 主题 | 深色为主 + 纸白浅色 | 已有跟随系统，不能砍 |
| 强调色 | **单一琥珀**，删除 6 色选择器 | 可换的颜色 = 没有精确的那一个颜色，硬件感不成立 |
| 圆角 | 6 / 10 / 14 / 18，禁用胶囊 | 胶囊是旧版语言 |
| 导航 | N1 导轨 + **纯文字** | 加图标会被读成"手机 App 底部导航" |
| Logo | 用户提供的实心折角 S，段 0 琥珀 | 细线版在小尺寸消失；段 0 是唯一不破坏轮廓的分段染色 |
| 层级手段 | 面板色差 + 1px 发丝线 + 顶沿内高光 | **不用外阴影** —— 外阴影是软塑料的来源 |
| 厚度 | 只有播放键有厚度 | 厚度是稀缺资源 |
| 按下 | `translateY(1px)` + 内阴影 | 缩放是软件模仿物理，位移才是物理 |
| 歌词 | 常驻三行，点击向上弹出整页 | 翻转把本该同时存在的两样东西做成互斥 |

## 五、风险

- **网易云无登录 cookie**：版权曲目会返回试听，我们一律判失败并回退 B 站 ——
  所以"某些歌网易云搜到了却从 B 站播"是预期行为，不是 bug。
- **B 站直链有时效**（约 2 小时）：长播列表需要在过期前重新解析，目前靠 10 分钟缓存兜底。
- **本机锚点不跨设备**：换机或清数据即丢失；服务端锚点仍只在配了服务端时生效。
