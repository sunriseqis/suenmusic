# 哑光硬件 UI 迁移 · 计划与进度

> 2026-10-18。设计方向已拍板，第一阶段（token + 基础组件 + 播放页 + 列表）已落地并真机验证。  
> ⚠️ **架构更新（2026-10-20）**：下方「〇、架构原则」与相关直连模式描述属于 10-18 历史探索；2026-10-20 已拍板**彻底终止端侧直连与本地优先，全面回归服务端单一真相源架构**（详见 [`docs/plan/2026-10-20-回归服务端单一真相源架构方案.md`](2026-10-20-回归服务端单一真相源架构方案.md)）。哑光硬件 UI 视觉体系（材质、圆角、单琥珀、发丝线、MarkBold、WordMark 等）则完整保留并全面落地。

## 〇、架构原则（2026-10-18 用户明确）

**服务端只做三件事：数据同步、AI、cookie 下发。**
歌单导入、QQ 歌单、去重、备份都是客户端业务，不许绕服务端。
服务端挂了，本机数据仍是本机数据；任何手段（文件 / WebDAV）能还原即可。

## 一、已确认的设计决策

| 决策 | 结论 | 理由 |
|---|---|---|
| 视觉方向 | **哑光硬件（Matte Hardware）** | 同一族但比 neumorphism 现代一个世代：靠材质、比例、机械反馈，不靠拟真纹理 |
| 主题 | 深色为主 + 纸白浅色 | 已有跟随系统，不能砍 |
| 强调色 | **单一琥珀**，删除 6 色选择器 | 可换的颜色 = 没有精确的那一个颜色，硬件感不成立 |
| 圆角 | 6 / 10 / 14 / 18，禁用胶囊 | 胶囊是旧版语言 |
| 导航 | N1 导轨 + **纯文字** | 加图标会被读成"手机 App 底部导航" |
| Logo | 用户提供的实心折角 S，段 0 琥珀 | 细线版在小尺寸消失；段 0 是唯一不破坏轮廓的分段染色 |
| 层级手段 | 面板色差 + 1px 发丝线 + 顶沿内高光 | **不用外阴影** —— 外阴影是软塑料的来源 |
| 厚度 | 只有播放键有厚度 | 厚度是稀缺资源 |
| 按下 | `translateY(1px)` + 内阴影 | 缩放是软件模仿物理，位移才是物理 |
| 歌词 | 常驻三行，点击向上弹出整页 | 翻转把本该同时存在的两样东西做成互斥 |

## 二、已完成（真机验证）

### 设计系统
- `tokens.css`：颜色/圆角全部换新（深色 `#0E0F11` / 纸白 `#F2F0EA` / 琥珀 `#E8A33D`·`#B0650F`）
- `neu.css`：外阴影 → 面板色差 + 发丝线 + 内高光
- 基础组件：Button / IconButton / Input / Switch / Tabs / Slider / ListItem / Avatar
- 修正：`--accent` 曾被 `ui.ts` 用 inline style 覆盖成旧橙色，已移除

### 结构
- 设置页：无服务端为**单页无 tab**（播放 / 资料库 / 设备 / 账号）；
  有服务端为「本机 / 智能 / 高级」三档。一次性任务全部走底部弹层
- 导航改 N1 纯文字导轨
- 列表去卡片化：搜索 / 收藏 / 歌单 / 每日推荐统一为"平铺 + 发丝线"
- 播放页结构对齐稿子：顶栏（返回 / `播放状态 · 播放来源` / 三点锚定）、
  标题左对齐 + 收藏在右、五键（仅播放键有厚度）、歌词常驻
- 收藏标记：去掉封面角标，改为**序号染琥珀**（收藏页关闭）
- 歌词页：点击三行歌词，从底部推出（340ms）

### 能力
- 锚定在直连模式可用：本机候选搜索 + 本机锚点表 + 解析时锚点优先
- **网易云直连**：旧接口无需加密；试听即失败；歌手命中守卫；失败回退 B 站
- **业务功能客户端化**：QQ 歌单导入（直连 module）、本机去重、`.sm` 备份
- **登录守卫已移除**：登录只从设置页弹层发起
- **服务端断开状态**：首次失败 toast 一次；设置页标题下常驻「服务端已断开」，
  任一请求成功或登出后消失

## 五、风险

- **网易云无登录 cookie**：版权曲目会返回试听，我们一律判失败并回退 B 站 ——
  所以"某些歌网易云搜到了却从 B 站播"是预期行为，不是 bug。
- **B 站直链有时效**（约 2 小时）：长播列表需要在过期前重新解析，目前靠 10 分钟缓存兜底。
- **本机锚点不跨设备**：换机或清数据即丢失；服务端锚点仍只在配了服务端时生效。
