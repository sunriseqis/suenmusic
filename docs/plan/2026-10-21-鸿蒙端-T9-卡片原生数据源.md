# 2026-10-21 鸿蒙端 T9：桌面卡片改原生数据源 + 设置页卡片管理

> 前置：T6（WebView 壳删除）通过。
> 现状：卡片数据链路是 WebView 时代设计的 —— `HarmonyAVSessionManager` 在 `common/` 有一份
> 服务原生模式，`pages/Index.ets` 里还有一份服务旧壳；卡片按钮经
> `postCardAction → callee → PlayerControlHub`，原生模式下已直驱 `MediaPlayerCore`（T2 期间修好）。
> **本单把数据链路收干净 + 给设置页加管理入口。**
> 卡片 UI（`forms/SuenFormCard.ets`，470 行）**样式不动**，只换数据源。

## 一、数据链路收敛（核心）

### 1.1 目标拓扑

```
MediaPlayerCore（唯一状态 owner）
  ├─ 写 NowPlaying 快照文件（复用 common/NowPlaying.ets 的 writeSnapshotSync）
  │    └─ SuenFormAbility.updateForm() 读快照 → 卡片渲染
  └─ AppStorage（K_TITLE/K_ARTIST/K_COVER/K_PLAYING/K_POS/K_DUR/K_INDEX）
       └─ 页面 UI 用
```

要求：
1. **`MediaPlayerCore` 的每次状态变化都同步写快照**（装载/播放/暂停/seek/缓存命中）。
   现在快照写在 `HarmonyAVSessionManager`（卡片侧主动读），要改成**内核推送**——
   卡片进程被杀后重启，靠 `readSnapshotSync` 恢复，所以快照必须始终新鲜。
2. **快照写入频率**：元数据变化即时写；进度**≤1 秒一次**（与 AVSession 节流共用一个闸，
   不要两条节流各自为政）。
3. **卡片按钮指令路径不变**：`callee('control') → PlayerControlHub.dispatchCardControl →
   MediaPlayerCore`。删掉其中仍残留的 WebView 分支与 `isWebPageReady()` 语义。
4. **删除 `Index.ets` 里那份 `HarmonyAVSessionManager` 副本**（T6 删壳时应已随文件消失；
   若 T6 保留了它的其它调用，本单把 `common/` 版本收敛为唯一实现）。
5. `updateDuration` 保持 `1`（=30 分钟）；主动刷新仍靠播放事件驱动的 `updateForm`。

### 1.2 卡片显示内容核对（官方约束见 docs/memory §7.4）

| 卡片元素 | 数据源 | 备注 |
|---|---|---|
| 标题/歌手 | 快照 title/artist | 空 = 「暂无歌曲播放」 |
| 封面 | 快照 coverUrl → 下载落盘 → formImages fd | 单文件 ≤2MB（现有守卫保留） |
| 播放/暂停图标 | 快照 playing | |
| 红心 | 快照 favorite | **需要新增**：原生没有收藏状态 —— 见 §二.3 |
| 歌词行 | 快照 lyric + positionMs | `parseLyricLines` 已有；歌词来源 = T1 的 `LyricView` 同源 API |
| 进度条 | positionMs/durationMs | |

## 二、新增能力

### 2.1 收藏状态进卡片
- `MediaPlayerCore` 增加 `currentFavorite: boolean`（由页面/收藏服务在切歌与收藏动作后写入）
- `SettingsPage`（或播放页红心）调 `POST/DELETE /api/favorites` 后同步更新它
- 快照的 `favorite` 字段取这个值（原来由 Web 通过 bridge 上报，现在来自原生收藏服务）

### 2.2 歌词进卡片
- 播放内核装载新曲时，后台拉 `GET /api/lyrics/:id`（失败静默，卡片歌词区显示占位）
- 复用 `NowPlaying.parseLyricLines`；`currentLyric` 随快照更新
- 歌词请求失败**不重试轰炸**（一首歌最多拉一次，切歌重置）

### 2.3 设置页「桌面卡片」区（T8 之上的新增条目）
- 「在桌面卡片上显示歌词」开关（preferences，默认开；关了快照 lyric 置空）
- 「卡片进度推送间隔」说明文案（受官方 30 分钟定时/50 次每日配额约束，主动推送由播放驱动）
- 显示当前已添加卡片数（`getPublishedRunningFormInfos`，失败按 T2 经验静默）

## 三、验收（8 条）

| # | 操作 | 判定 |
|---|---|---|
| 1 | 播放时看桌面卡片 | 标题/歌手/封面与播放页一致，进度条走 |
| 2 | 卡片播放/暂停/上一首/下一首 | 全部生效（经 callee → 内核），无 WebView 残留 |
| 3 | 收藏一首（播放页红心） | 卡片红心变实心；取消收藏变空心 |
| 4 | 有歌词的歌 | 卡片歌词随播放滚动；无歌词歌显示占位不报错 |
| 5 | 杀掉应用进程 → 点卡片播放键 | 冷启动到 NativeRoot 并执行指令；快照在冷启动后仍显示上次曲目 |
| 6 | 「显示歌词」开关关掉 | 卡片歌词区消失/占位，播放不受影响 |
| 7 | 长时任务一致性 | 卡片控制暂停后 30 秒内长时任务取消（回归门禁） |
| 8 | 回归 | `arkts_check` 0 ERROR；无 `SetAVPlaybackState timeout` 刷屏；颜色全走 Tokens |
