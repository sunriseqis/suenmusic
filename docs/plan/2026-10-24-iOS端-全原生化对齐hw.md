## 六、分发方式（用户 2026-10-24 定稿）

> 最终和 hw 一样：**无签名 IPA 产物**，走**本地侧载工具签名**。

因此：

- **不做 App Store 上架链路**（ASC 元数据 / 审核 / PrivacyInfo.xcprivacy 强制项 / ATS 审核论证）—— 全部降级为可选，
  将来真要上架再按 `iosdev-cn` 技能补。
- 产物：`npm run ios:ipa:unsigned` → `app/unsigned/suenmusic-<版本>.ipa`
  （已核对脚本：`CODE_SIGNING_ALLOWED=NO` + `CODE_SIGNING_REQUIRED=NO` + `CODE_SIGN_IDENTITY=""`，Payload 直接 zip）。
- **命名已对齐**：`build-ios.mjs` 产物名从旧 `SuenMusic-v<版本>-release.ipa` 改为 **`suenmusic-<版本>.ipa`**，
  与服务端 `artifactName()`、鸿蒙 `suenmusic-<版本>.hap` 完全同口径（同版本覆盖同名）。
- 安装路径：侧载工具（AltStore / Sideloadly / TrollStore 等）重签后装；`/api/update/download?platform=ios&token=…` 直链可直接喂给这些工具。
- 版本号：`MARKETING_VERSION`/`CURRENT_PROJECT_VERSION` 由 `build-ios.mjs` 从根 `VERSION` 注入（`2.0.0 / 2000000`）。

## 八、批④（播放页 + 失败语义）落地明细

对齐源：hw `core/MediaPlayerCore.ets` 的失败语义 + `pages/PlayerPage.ets` 的呈现规格。

### 状态机（PlaybackService，与 hw 逐条对应）

| hw | iOS |
|---|---|
| `FAIL_GRACE_MS = 2500` 宽限，窗口内自愈就忽略 | `scheduleFailureSettle()`：2.5s 后再判，`playing == true` 直接放弃 |
| `STALL_MS = 6000` 装载看门狗 | `armLoadWatchdog()`：6s 未进 playing → 走同一条失败路径 |
| `MAX_FAIL_STREAK` 连环失败 → 通知 + 暂停 | `failStreak >= 2` → 暂停 + 「连续多首没有匹配音源」通知 |
| 连播失败且还有下一首 → 清错误 + 通知 + 600ms 后 `advance(true)` | `!manualLoad && hasWayOut` → 通知 + 600ms 后 `next()`（手动标记复位）|
| 手动点播失败 → 停在当前曲，`np_error = '无音源'` | `noSource = true` → eyebrow 显示「无音源」（danger 色）|
| `settleFailure` 必须推 paused，避免系统卡片外推进度 | `engine?.pause()` + `playing = false` |
| `manualLoad`：setQueue/jumpTo=true、advance=false | `play()`/`next()`/`prev()` = true；`emitTrackChange(reason: 1)`（播完自动切）= false |

### 呈现（PlayerView）

- 顶栏：收起（chevron-down，44 触控区，主文字色）+ 居中 eyebrow（`无音源`/错误 → danger；否则「正在播放/已停止 · 来源」）
- 封面：环境光晕（`Dim.glowBlur`）+ 280×280 圆角卡 + 发丝描边
- 曲名 `fsHero`、「歌手 · 专辑」、`音源：bilibili/网易云/未匹配`（hw `sourceLabel` 同口径）
- 进度：Slider + 左右时间（`fsCaption`）；三键：上一首 / 64 圆主键（accent 底）/ 下一首
- **没有错误横幅、没有重试/跳过按钮** —— 与 hw 的定稿规格一致

### 新增

- `Player/Notifier.swift`：`UNUserNotificationCenter` 本地通知（授权被拒静默降级），只在「连播跳过 / 连续失败」用，手动失败不发。

### 未做（后续批次）

- 「更多」菜单（修正音源/不喜欢/移出队列）、歌词面板（`LyricView` 等价物）、队列视图。
