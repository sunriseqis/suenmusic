- 分组标题 = 小字（`Dim.fsCaption`、`Tokens.text2`），条目行 = `Dim.rowHeight`

- 箭头 `>` 用 Symbol；整行可点的用行点击，不用按钮

## 一、分区与条目（缺一不算全）

### ① 账号区（保留现有，加项）
- 用户名 / 角色（admin 显示"管理员"）
- **修改口令** → `PATCH /api/auth/password`（现有接口，查 server/src/routes/auth.ts 确认形状）
- 退出登录（红字，二次确认）

### ② 服务器区
- 当前服务端地址（只读展示 + 「管理」入口 → 跳多服务端编辑页，T3 产物）
- 「自动切换服务器」开关（T4 产物）

### ③ 播放区
- 「自动播放下一首」开关（本地偏好，`preferences`；接 `MediaPlayerCore` 的接续逻辑——
  若接续开关为关，`endOfStream` 停住不跳）
- 「歌词翻译显示」开关（T4 产物）
- 「停顿自愈」开关（默认开；关了就不跑 10s stall 看门狗——若 T4 没做看门狗开关，此条并入）

### ④ 缓存区（入口页）
- 已用 / 配额（`OfflineCache.usedBytes()` / `quotaBytes()`）+ 进度条
- 「管理缓存」入口 → 离线缓存面板页（T3 产物）

### ⑤ 更新区（T7 产物）
- 当前版本（`bundleManager.getBundleInfoForSelfSync()`，不要硬编码）
- 「检查更新」按钮 + 状态文案（已是最新 / 发现 vX.Y.Z / 失败人话）
- 发现新版本 → 「下载并安装」→ 打开系统浏览器交给侧签工具

### ⑥ 外观区
- 主题跟随系统（默认）/ 深色 / 浅色（本地偏好；本阶段深浅只是存偏好，视觉令牌已是深色）

### ⑦ 关于区
- 应用版本、服务端 API 版本（`/api/health` 的 version）
- 开源许可、致谢（静态文本）

## 二、统一要求

- 全部颜色走 `Tokens.*`；尺寸走 `Dim.*`（T5 产物）
- 所有开关状态持久化到 `preferences`，重启保留；**文案进 `Copy.ets`**
- 每个开关改完立即生效，不需要"保存"按钮
- 列表滚动流畅（`List` + 分组头），进入/退出不影响后台播放

## 三、验收（10 条）

| # | 条目 | 判定 |
|---|---|---|
| 1 | 账号区 | 用户名/角色正确；改口令后旧口令登不上、新口令能登 |
| 2 | 服务器区 | 地址正确显示；点管理进多服务端页 |
| 3 | 自动切换开关 | 关掉后断网不换服（T4 验收的回归） |
| 4 | 自动播放下一首 | 关掉后一首放完不跳；开回恢复 |
| 5 | 歌词翻译开关 | 与 T4 行为一致，重启保留 |
| 6 | 缓存区 | 用量/配额与实际一致；入口能进缓存面板 |
| 7 | 更新区 | 版本号与 bundleManager 一致；检查更新人话反馈 |
| 8 | 外观偏好 | 重启保留 |
| 9 | 关于区 | 版本、API 版本正确 |
| 10 | 回归 | 退出设置页后台播放/锁屏仍正常；无 `SetAVPlaybackState timeout`；`arkts_check` 0 ERROR |
